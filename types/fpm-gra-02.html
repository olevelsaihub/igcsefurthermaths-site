Knowledge card

Drawing the graph from your table

Written

To plot a curve from a table, plot every point exactly, then join them with one smooth freehand curve over the interval asked for, never with straight segments.

1

Plot, then draw the curve

3 points to find

Which points need extra care when you plot them?

  1. The top of the hump
  2. The origin is a point too
  3. Last point of the interval

The top of the hump

Why
The curve turns at $(-1, 2)$, so plot it with care.
Trap
Joining straight through it misses the hump.

The origin is a point too

Why
The curve passes through $(0, 0)$, so plot it like the others.

Last point of the interval

Why
The interval ends at $x = 2$: stop there.
0 of 3 found

3 points to find

Which point needs a different scale, and why?

  1. Stay above the x-axis
  2. The y-intercept
  3. Top point needs a scale

Stay above the x-axis

Trap
$y$ is never zero or negative, so the curve never touches the $x$-axis.

The y-intercept

Why
$(0, 1)$ is the $y$-intercept: a check that the curve is right.

Top point needs a scale

Why
$8$ is far above $1$, so choose the $y$-scale before you plot.

Exam question

Using the table for $y = x^3 - 3x$, draw the curve for $-2 \leqslant x \leqslant 2$, plotting all five points. (2 marks)

5

The method

  1. Read the scale

    Work out what one small square is worth on each axis.

  2. Plot every point

    Plot each column of the table with a small neat cross.

  3. Check odd points

    If a point does not fit its neighbours, recalculate it.

  4. Draw one smooth curve

    One freehand line through all the points, not joined dots.

  5. Stop at the interval

    Start and finish at the ends of the interval given.

Do not lose marks here

  • ✗
    Straight segments

    Joining points with a ruler gives a different graph.

  • ✗
    Bending to a bad point

    Recalculate a wrong value; do not force the curve through it.

What a complete response includes

Usually two marks: one for plotting all the points correctly (this can follow through from wrong table values) and one for a smooth curve through them over the interval.

Drawing the graph from your table · June 2025 · Paper 2 · Question 7 · part (b) · 2 marks

On the grid, draw the graph of $y = 3 + \log_3(4 - x)$ for $0 \leqslant x \leqslant 3.5$, using the completed table from part (a).

Worked explanation

  1. Completed table: $(0, 4.26)$, $(0.5, 4.14)$, $(1, 4)$, $(1.5, 3.83)$, $(2, 3.63)$, $(2.5, 3.37)$, $(3, 3)$, $(3.5, 2.37)$
  2. Plot all eight points as small crosses, checking the scale on the $y$-axis
  3. Notice the gaps between $y$-values grow: $0.12, 0.14, 0.17, 0.20, 0.26, 0.37, 0.63$, so the curve gets steeper to the right
  4. Draw one smooth curve from $(0, 4.26)$ to $(3.5, 2.37)$, curving downwards ever more steeply (the curve is heading for the asymptote $x = 4$)
  5. Do not extend past $x = 3.5$
Model answer · written by olevels.com, not an official Pearson mark scheme

A smooth decreasing curve through the eight points from $(0, 4.26)$ to $(3.5, 2.37)$, getting steeper as $x$ increases.

How the marks are earned

One mark for all eight points plotted correctly and one mark for a smooth curve through them across $0 \leqslant x \leqslant 3.5$.

Calculation check

  • round(4.26-4.14,2) = 0.12
  • round(3-2.37,2) = 0.63
  • round(3 × × (2.37-3),2) = 0.5
