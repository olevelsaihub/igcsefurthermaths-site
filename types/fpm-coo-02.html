Knowledge card

Midpoints and points that split a line in a ratio

Calculation

A midpoint averages each pair of coordinates. A point splitting a line in a ratio $m : n$ moves $\frac{m}{m+n}$ of the way from the first end.

The calculation

$P = \left(\frac{n x_1 + m x_2}{m + n},\ \frac{n y_1 + m y_2}{m + n}\right)$ for $AP : PB = m : n$

Midpoint: $\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$

5

The method

  1. Name the ends

    Write the two points and say which is first.

  2. Use the rule

    Average the coordinates for a midpoint, or weight them by the ratio parts.

  3. Check the answer

    A ratio point should lie between the two ends, nearer the end with the smaller part.

Do not lose marks here

  • ✗
    Ratio on the wrong end

    Give $m$ to the end next to $A$, then check the point is nearer $B$ when $m > n$.

  • ✗
    Dividing by the wrong total

    Use $m + n$ parts, not $n$.

What a complete response includes

Usually two marks: a method mark for a correct use of the ratio (formula or steps) for at least one coordinate, and an accuracy mark for the correct point. In show-that versions the accuracy mark needs the printed coordinates reached with working shown. Parallelogram or reverse versions add a method mark for setting up the unknown end point correctly.

Midpoints and points that split a line in a ratio · June 2024 · Paper 1 · Question 6 · part (a) · 2 marks

The line $l$ passes through the point $A$ with coordinates $(-2, 2)$ and the point $B$ with coordinates $(3, 12)$. The point $C$ with coordinates $(p, q)$ lies on $l$ such that $AC : CB = 3 : 2$. (a) Find the value of $p$ and the value of $q$.

After your attempt, see the full worked explanation

Worked explanation

  1. Total parts: $3 + 2 = 5$, so $C$ is $\frac{3}{5}$ of the way from $A$ to $B$.
  2. Change from $A$ to $B$: $\Delta x = 3 - (-2) = 5$, $\Delta y = 12 - 2 = 10$.
  3. $p = -2 + \frac{3}{5} \times 5 = -2 + 3 = 1$
  4. $q = 2 + \frac{3}{5} \times 10 = 2 + 6 = 8$
  5. Formula check: $p = \frac{2(-2) + 3(3)}{5} = \frac{5}{5} = 1$, $q = \frac{2(2) + 3(12)}{5} = \frac{40}{5} = 8$.
Model answer · written by olevels.com, not an official Pearson mark scheme

$p = 1$, $q = 8$

How the marks are earned

A method mark for a correct ratio method on at least one coordinate (for example $\frac{2(-2) + 3(3)}{5}$), then an accuracy mark for both values correct.

Calculation check

  • (2 × (-2)+3 × 3) ÷ 5 = 1
  • (2 × 2+3 × 12) ÷ 5 = 8
