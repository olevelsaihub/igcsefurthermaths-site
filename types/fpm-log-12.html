Simultaneous equations with powers and logs

Turning a pair of index and log equations into ordinary algebraic equations in x and y and solving them together.

★☆☆☆☆ · 5 of 44 eligible examination papers, 2019–2025. Difficulty: Very Difficult.

Simultaneous equations with powers and logs

Calculation

For simultaneous index and log equations, write both sides as powers of one base or remove the logs. Solve the two resulting equations together, then check every pair.

Which step removes a log?

  1. Write 9 as 3²
  2. Remove the log
  3. Check both equations

Write 9 as 3²

Why
$9^y = (3^2)^y = 3^{2y}$, so the powers can be equated.

Remove the log

Working
$\log_2 P = 3$ means $P = 2^3 = 8$.

Check both equations

Why
Both equations must hold; one check is not enough.

2 steps to find

Which step turns the log into a power?

  1. Write 4 as 2²
  2. Remove the log

Write 4 as 2²

Working
$4^y = (2^2)^y = 2^{2y}$, so the total power is $x + 2y$.

Remove the log

Why
$\log_3\frac{x}{y} = 1$ means $\frac{x}{y} = 3^1 = 3$.

2

The calculation

$a^x = a^y \Rightarrow x = y$, and $\log_a P = c \Rightarrow P = a^c$

Tap a part to see what it means and how to find it.

  • Index slip: $243 = 3^5$, not $3^4$
  • Rounding before the last step

Try itSolve $2^x = 8^y$ and $x + y = 8$.

  1. $8 = 2^3$, so $2^x = 2^{3y}$ and $x = 3y$
  2. $3y + y = 8$, so $y = 2$ and $x = 6$

5

The method

  1. Equate powers

    Write both sides of an index equation as powers of one base.

  2. Remove logs

    Use index form for each log equation.

  3. Make a substitution

    Make one unknown the subject of one equation.

  4. Solve

    Substitute into the other equation.

  5. Check both

    Each pair must satisfy both original equations.

Do not lose marks here

  • ✗
    Base not matched

    $4^x$ is $2^{2x}$, not $2^x$.

  • ✗
    Dropping the log

    A log equation must become index form, not stay as a log.

What a complete response includes

Method and accuracy marks for each equation correctly rewritten without logs or powers, a method mark for substituting one into the other, a method mark for solving the resulting equation, and accuracy marks for each unknown. Rejecting an invalid pair is needed for the final accuracy mark.

Giving each value in your solution to 2 decimal places, solve the simultaneous equations $e^{2y} - x + 2 = 0$ and $\ln(x + 3) - 2y - 1 = 0$.

Worked explanation

  1. From the first equation: $e^{2y} = x - 2$
  2. From the second equation: $2y + 1 = \ln(x + 3)$, so $x + 3 = e^{2y + 1} = e \cdot e^{2y}$
  3. Substitute $e^{2y} = x - 2$: $\;x + 3 = e(x - 2)$
  4. $x + 3 = ex - 2e \Rightarrow 2e + 3 = ex - x = x(e - 1)$
  5. $x = \frac{2e + 3}{e - 1} = 4.9098\ldots$
  6. $e^{2y} = x - 2 = 2.9098\ldots \Rightarrow 2y = \ln 2.9098\ldots = 1.0681\ldots$
  7. $y = 0.5340\ldots$
  8. Check: $x + 3 = 7.9098\ldots > 0$ and $x - 2 > 0$, so the logs are defined.
Model answer · written by olevels.com, not an official Pearson mark scheme

$x = 4.91$, $y = 0.53$ (2 d.p.)

How the marks are earned

Method marks for rewriting each equation without ln (e.g. $e^{2y} = x - 2$ and $x + 3 = e^{2y+1}$), a method mark for substituting one into the other to get an equation in $x$ only, a method mark for solving it, accuracy for $x = 4.91$, a method mark for taking logs to find $y$, and accuracy for $y = 0.53$. Values should be kept unrounded until the end.
