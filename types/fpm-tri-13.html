Lengths in a 3D solid using right-angled triangles

Calculation

Pythagoras works in any right-angled triangle drawn inside a solid. For a right pyramid, the vertex is above the centre of the base, so use half the base diagonal.

5

The method

  1. Sketch the solid

    Draw the right-angled triangle that contains the length you need.

  2. Find half the base diagonal

    From the centre to a corner of a square of side $s$ is $\frac{s\sqrt{2}}{2}$.

  3. Apply Pythagoras

    Square the two shorter sides, add them, then take the square root.

  4. Simplify

    Keep the surd exact and simplify it if asked.

Do not lose marks here

  • ✗
    Full diagonal

    The triangle uses half the diagonal, from the centre to a corner.

  • ✗
    Vertical height

    A sloping edge is not the height: the height is the vertical line from the apex.

Lengths in a 3D solid using right-angled triangles · November 2025 · Paper 2 · Question 11 · part (a) · 3 marks

$ABCDE$ is a right pyramid with vertex $E$ and horizontal square base $ABCD$ of side 6 cm. $EA = EB = EC = ED = 12$ cm and the vertical height is $h$ cm. (a) Show that $h = 3\sqrt{14}$.

Worked explanation

  1. Diagonal $AC = \sqrt{6^2 + 6^2} = \sqrt{72} = 6\sqrt{2}$
  2. Let $O$ be the centre of the base (below $E$). $AO = \frac{1}{2}AC = 3\sqrt{2}$
  3. Triangle $EOA$ is right-angled at $O$: $h^2 = EA^2 - AO^2 = 144 - 18 = 126$
  4. $h = \sqrt{126} = \sqrt{9 \times 14} = 3\sqrt{14}$
Model answer · written by olevels.com, not an official Pearson mark scheme

$h = 3\sqrt{14}$

How the marks are earned

A method mark for half the base diagonal, a method mark for Pythagoras in triangle EOA, and the accuracy mark for reaching 3 root 14 with the surd simplification shown.
