Log equations: combine into one log, then remove the log

Log equations in one unknown that are solved by bringing every log to one base (by change of base if needed), combining them with the laws of logs and converting to index form.

Type 6 1 Logarithms, indices and surds FPM-LOG-07

★★★★☆ · 12 of 44 eligible examination papers, 2019–2025. Difficulty: Difficult.

An equation in one unknown with two or more logs, possibly in different bases such as $\log_4 x$, $\log_{16} x$ and $\log_2 x$, or with numbers mixed in, asking you to 'solve' or 'show that'. The logs can be gathered into one log with no $\log x$ ever ending up in a denominator.

Knowledge card

Log equations: combine into one log, then remove the log

Calculation

To solve a log equation, bring every log to one base, combine them with the log laws, then remove the log. Always check that each log argument is positive.

Which step changes the base?

  2. Index form removes the log
  3. Check the answer

Divide by log_2 4

Working
$\log_4 x = \frac{\log_2 x}{\log_2 4} = \frac{1}{2}\log_2 x$.
Trap
Do not write $\log_4 x = \log_2 x$.

Index form removes the log

Why
$\log_2 x = 2$ means $x = 2^2 = 4$.

Check the answer

Why
Substituting back confirms $3 = 3$.

3 steps to find

Which law combines the two logs?

  1. Quotient, not difference
  2. Solve the linear equation
  3. Check the domain

Quotient, not difference

Why
Subtracting two logs of one base divides their arguments.

Solve the linear equation

Working
$x + 6 = 9x \Rightarrow 8x = 6 \Rightarrow x = \frac{3}{4}$.

Check the domain

Why
Each argument must be positive: $x > 0$ and $x + 6 > 0$.

The calculation

$\log_a x + \log_a y = \log_a(xy)$, $\log_a x - \log_a y = \log_a\frac{x}{y}$, $\log_a x = \frac{\log_b x}{\log_b a}$

Tap a part to see what it means and how to find it.

  • A law applied to a sum: $\log(x + 3) \neq \log x + \log 3$
  • Dropping the divisor in a change of base

Try itSolve $\log_5(x - 1) + \log_5(x + 3) = 1$.

  1. $(x - 1)(x + 3) = 5$, so $x^2 + 2x - 8 = 0$
  2. $(x + 4)(x - 2) = 0$, so $x = 2$; $x = -4$ is rejected since $x - 1 < 0$

5

The method

  1. One base

    Change every log to one base, usually the smallest.

  2. Coefficients inside

    Turn $k\log_a x$ into $\log_a x^k$ where needed.

  3. Combine

    Use the product or quotient law to get one log.

  4. Remove the log

    Use index form, or equate the arguments.

  5. Check the domain

    Reject any value that makes a log argument zero or negative.

Do not lose marks here

  • ✗
    Log of a sum

    $\log(x + 3)$ does not split into two logs.

  • ✗
    Keeping an invalid root

    A root that makes a log argument negative must be rejected.

What a complete response includes

A method mark for a correct change of base, a method mark for correctly combining the logs with the laws, a method mark for removing the logs to form an algebraic equation, and accuracy marks for the correct solution(s), with any invalid root rejected. Longer versions that end in a quadratic carry extra method marks for solving it.

Solve the equation $\log_4 x + \log_{16} x + \log_2 x = 10.5$. Show your working clearly.

Worked explanation

  1. Change to base 2: $\log_4 x = \frac{\log_2 x}{\log_2 4} = \frac{1}{2}\log_2 x$ and $\log_{16} x = \frac{\log_2 x}{\log_2 16} = \frac{1}{4}\log_2 x$
  2. $\frac{1}{2}\log_2 x + \frac{1}{4}\log_2 x + \log_2 x = 10.5$
  3. $\frac{7}{4}\log_2 x = \frac{21}{2}$
  4. $\log_2 x = 6$
  5. $x = 2^6 = 64$
  6. Check: $\log_4 64 + \log_{16} 64 + \log_2 64 = 3 + 1.5 + 6 = 10.5$
Model answer · written by olevels.com, not an official Pearson mark scheme

$x = 64$

How the marks are earned

Method marks for changing $\log_4 x$ and $\log_{16} x$ correctly to base 2, a method mark for collecting the terms into a single multiple of $\log_2 x$, a method mark for converting $\log_2 x = 6$ to index form, and an accuracy mark for $x = 64$.

Calculation check

  • 10.5 ÷ (1 ÷ 2+1 ÷ 4+1) = 6
  • 2 × × 6 = 64
  • 3+1.5+6 = 10.5
