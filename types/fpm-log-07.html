Log equations: combine into one log, then remove the log

Log equations in one unknown that are solved by bringing every log to one base (by change of base if needed), combining them with the laws of logs and converting to index form.

Type 6 1 Logarithms, indices and surds FPM-LOG-07

★★★★☆ · 12 of 44 eligible examination papers, 2019–2025. Difficulty: Difficult.

An equation in one unknown with two or more logs, possibly in different bases such as $\log_4 x$, $\log_{16} x$ and $\log_2 x$, or with numbers mixed in, asking you to 'solve' or 'show that'. The logs can be gathered into one log with no $\log x$ ever ending up in a denominator.

Knowledge card

Log equations: combine into one log, then remove the log

Written
  • Product law: $\log_a x + \log_a y = \log_a (xy)$.
  • Quotient law: $\log_a x - \log_a y = \log_a \frac{x}{y}$.
  • Power law: $k\log_a x = \log_a x^k$ (it applies to a single log, never to a sum inside the log).
  • Change of base: $\log_a x = \frac{\log_b x}{\log_b a}$; for example $\log_4 x = \frac{\log_2 x}{2}$ and $\log_{16} x = \frac{\log_2 x}{4}$.
  • $\log_a b = \frac{1}{\log_b a}$, and $\log_a a = 1$, so a plain number $k$ can be written as $\log_a a^k$.
  • Once you have $\log_a(\text{stuff}) = c$, remove the log: stuff $= a^c$; or from $\log_a P = \log_a Q$, deduce $P = Q$.
  • Always check that every value you keep makes each log argument positive.

Before you begin

  • The definition of a log and switching to index form (FPM-LOG-01).
  • Index laws, including fractional powers.
  • Solving linear and quadratic equations.
1

The method

  1. If the bases differ, change every log to one base, usually the smallest (e.g. base 2 for bases 4 and 16).

    Why: The laws of logs only combine logs with the same base.

  2. Move coefficients inside as powers ($k\log_a x = \log_a x^k$) and write any plain number as a log of the same base.

    Why: This prepares every term to be combined.

  3. Use the product and quotient laws to combine everything into a single log on each side (or one log equal to a number).

    Why: A single log can be removed in one step.

  4. Remove the logs: $\log_a P = c \Rightarrow P = a^c$, or $\log_a P = \log_a Q \Rightarrow P = Q$.

    Why: This leaves an ordinary linear or quadratic equation.

  5. Solve, then reject any value that makes a log argument zero or negative, and give the answer in the form asked.

    Why: Logs of non-positive numbers are undefined.

Do not lose marks here

  • ✗
    Applying a law to a sum: writing $\log(x + 3)$ as $\log x + \log 3$.
  • ✗
    Dropping the divisor in change of base, e.g. writing $\log_4 x = \log_2 x$ instead of $\frac{1}{2}\log_2 x$.
  • ✗
    Turning $\log_a P = c$ into $P = c^a$ or $P = ac$.
  • ✗
    Keeping a root that makes a log argument negative.
  • ✗
    Forgetting to change a plain number (like 1 or 3) into a log before combining, so the logs are 'removed' wrongly.

Common mistakes: Inferred, not measured. Inferred from typical examiner credit patterns for this method; not measured student-error statistics.

Now see it used on a real past-paper question

What a complete response includes

A method mark for a correct change of base, a method mark for correctly combining the logs with the laws, a method mark for removing the logs to form an algebraic equation, and accuracy marks for the correct solution(s), with any invalid root rejected. Longer versions that end in a quadratic carry extra method marks for solving it.

Log equations: combine into one log, then remove the log · June 2022 · Paper 2 · Question 10 · part (whole) · 5 marks

Solve the equation $\log_4 x + \log_{16} x + \log_2 x = 10.5$. Show your working clearly.

Question restated by olevels.com from the original paper; the original is below.

View full original question and diagrams
After your attempt, see the full worked explanation

Worked explanation

  1. Change to base 2: $\log_4 x = \frac{\log_2 x}{\log_2 4} = \frac{1}{2}\log_2 x$ and $\log_{16} x = \frac{\log_2 x}{\log_2 16} = \frac{1}{4}\log_2 x$
  2. $\frac{1}{2}\log_2 x + \frac{1}{4}\log_2 x + \log_2 x = 10.5$
  3. $\frac{7}{4}\log_2 x = \frac{21}{2}$
  4. $\log_2 x = 6$
  5. $x = 2^6 = 64$
  6. Check: $\log_4 64 + \log_{16} 64 + \log_2 64 = 3 + 1.5 + 6 = 10.5$
Model answer · written by olevels.com, not an official Pearson mark scheme

$x = 64$

How the marks are earned

Method marks for changing $\log_4 x$ and $\log_{16} x$ correctly to base 2, a method mark for collecting the terms into a single multiple of $\log_2 x$, a method mark for converting $\log_2 x = 6$ to index form, and an accuracy mark for $x = 64$.

Calculation check

  • 10.5 ÷ (1 ÷ 2+1 ÷ 4+1) = 6
  • 2 × × 6 = 64
  • 3+1.5+6 = 10.5
