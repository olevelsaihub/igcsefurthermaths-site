Finding n from an equation linking sums and terms

Calculation

To find $n$, write $S_n$ and $S_{2n}$ in $n$, which gives a quadratic. Keep only a positive whole root.

  1. Write S_n

    Find $a$, $d$ and write $S_n$ in $n$.

  2. Write S_2n

    Replace every $n$ by $2n$, with brackets.

  3. Form the equation

    Substitute into the relation.

  4. Solve and check

    Keep the positive whole root and check it.

Do not lose marks here

  • ✗
    Doubling the sum

    $S_{2n}$ is not $2S_n$.

  • ✗
    Both roots

    Reject any negative number of terms.

What a complete response includes

Method marks for correctly writing each sum or term as an expression in n and substituting into the relation, a method mark for solving the resulting quadratic, and an accuracy mark for the correct integer n (with any invalid root rejected).

Finding n from an equation linking sums and terms · January 2020 · Paper 1 · Question 1 · part (b) · 5 marks

An arithmetic series $A$ has first term $24$ and common difference $6$. For series $A$, the sum of the first $2n$ terms is $3$ times the sum of the first $n$ terms. (b) Find the value of $n$.

Figures check

After your attempt, see the full worked explanation

Worked explanation

  1. $S_n = \frac{n}{2}[2(24) + (n-1)6] = \frac{n}{2}(42 + 6n) = n(21 + 3n)$
  2. $S_{2n} = 2n(21 + 3(2n)) = 2n(21 + 6n)$
  3. $S_{2n} = 3S_n \Rightarrow 2n(21 + 6n) = 3n(21 + 3n)$
  4. $n \neq 0$, so divide by $n$: $42 + 12n = 63 + 9n$
  5. $3n = 21 \Rightarrow n = 7$
  6. Check: $S_7 = 7(21 + 21) = 294$ and $S_{14} = 14(21 + 42) = 882 = 3 \times 294$
Model answer · written by olevels.com, not an official Pearson mark scheme

$n = 7$

How the marks are earned

Method marks for a correct expression for S_n and for S_2n, a method mark for forming the equation S_2n = 3S_n, a method mark for simplifying and solving it, and an accuracy mark for n = 7.

Calculation check

  • 7 × (21+3 × 7) = 294
  • 14 × (21+3 × 14) = 882
  • 3 × 294 = 882
