Knowledge card

Angles and areas of triangles inside a solid

Calculation

A triangle drawn inside a solid is solved flat: find its sides with Pythagoras, then use the converse of Pythagoras or trig for an angle, and half base times height for an area.

Why
$125 = 100 + 25$, so the angle opposite $AG$ is $90^\circ$.

5

The method

  1. Name the triangle

    Choose the triangle in the solid that contains the angle you need.

  2. Find each side

    Use Pythagoras or the base edges to find all three sides.

  3. Test for a right angle

    If $a^2 + b^2 = c^2$, the angle opposite $c$ is $90^\circ$.

  4. Use the right tool

    Use trig in a right angle, or the cosine rule otherwise. A triangle's area is half base times height.

Do not lose marks here

  • ✗
    Wrong side length

    A wrong length early on spoils the angle.

  • ✗
    Assumed right angle

    Check a right angle with the converse before using it.

A right pyramid has a horizontal square base $ABCD$ with $AB = BC = CD = DA = x$ cm and $AV = BV = CV = DV = x$ cm. (b) Find, in degrees, the size of angle $AVC$.

Worked explanation

  1. Triangle $AVC$ has $VA = VC = x$ and $AC$ the base diagonal.
  2. $AC^2 = x^2 + x^2 = 2x^2$
  3. $VA^2 + VC^2 = x^2 + x^2 = 2x^2 = AC^2$
  4. By the converse of Pythagoras, the angle opposite $AC$ is a right angle (or: $\cos AVC = \frac{x^2 + x^2 - 2x^2}{2x^2} = 0$).
Model answer · written by olevels.com, not an official Pearson mark scheme

Angle $AVC = 90^\circ$

How the marks are earned

A method mark for finding AC (or AC^2 = 2x^2) and using it with VA and VC in the cosine rule or the converse of Pythagoras, and an accuracy mark for 90 degrees.
