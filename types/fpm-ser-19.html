When is a binomial expansion valid?

Calculation

A binomial series with a power that is not a positive whole number is valid only for $|bx| < 1$. Make the bracket start with 1 first, then take the modulus.

The calculation

$(1+bx)^n$ is valid for $|bx| < 1$, i.e. $|x| < \frac{1}{|b|}$

The sign inside the bracket does not change the range.

Tap a part to see what it means and how to find it.

  • Forgetting the modulus: writing $x < \frac{4}{3}$
  • Using the bracket before the constant was taken out

Try itState the range of validity for $(1+2x)^{-2}$.

  1. $|2x| < 1$, so $|x| < \frac{1}{2}$
  2. So $-\frac{1}{2} < x < \frac{1}{2}$.

The method

  1. Make it start with 1

    Take out the constant from the bracket.

  2. Find b

    Write the bracket as $(1 + bx)^n$.

  3. Apply |bx| < 1

    Divide by $|b|$ to get $|x| < 1/|b|$.

Do not lose marks here

  • ✗
    Missing modulus

    Both ends: $-\frac{1}{|b|} < x < \frac{1}{|b|}$.

  • ✗
    Inverted b

    The limit is $1 \div |b|$, not $|b|$.

(a) Expand $\left(1 + \frac{x}{3}\right)^{-3}$ in ascending powers of $x$ up to and including the term in $x^3$. (b) Write down the range of values of $x$ for which your expansion is valid.

Worked explanation

  1. The expansion is of $(1 + bx)^{-3}$ with $b = \frac{1}{3}$
  2. Valid when $\left|\frac{x}{3}\right| < 1$
  3. $|x| < 3$, i.e. $-3 < x < 3$
