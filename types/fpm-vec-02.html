How long is a vector? Magnitudes and finding unknowns

Working out the length of a vector with Pythagoras on its components (or the cosine rule for non-perpendicular base vectors), and reversing this to find an unknown constant when a length is given.

Type 4 7 Vectors FPM-VEC-02

★★☆☆☆ · 7 of 44 eligible examination papers, 2019–2025. Difficulty: Medium.

Look for $|\ldots|$ bars or the word 'magnitude' or 'length', either 'Find the magnitude of $\overrightarrow{AB}$' or a given length with an unknown inside the vector, such as 'Given that $|\overrightarrow{BD}|=3\sqrt{10}$, find the possible values of $p$'.

How long is a vector? Magnitudes and finding unknowns

Calculation

The length of $x\mathbf{i}+y\mathbf{j}$ is $\sqrt{x^2+y^2}$. For an unknown, square the length on both sides, solve, and give every value the question allows.

Given $|\overrightarrow{BD}|=5$, find $p$.

  1. Both j parts change sign
  2. Square the components
  3. Square the given 5

Both j parts change sign

Trap
$-p\mathbf{j}$ and $-p\mathbf{j}$ give $-2p\mathbf{j}$, not $0$.

Square the components

Working
$3^2+(-2p)^2=9+4p^2$

Square the given 5

Why
$|\overrightarrow{BD}|=5$, so set $9+4p^2=25$.

The calculation

$|x\mathbf{i}+y\mathbf{j}|=\sqrt{x^2+y^2}$

Square the length first: $|\mathbf{v}|^2=x^2+y^2$.

Tap a part to see what it means and how to find it.

  • Squaring only part of a component, e.g. $(2p+1)^2=4p^2+1$
  • Not squaring the given length

Try it$|3\mathbf{i}+k\mathbf{j}|=5$. Find $k$.

  1. $9+k^2=5^2=25$, so $k^2=16$
  2. $k=4$ or $k=-4$

$\overrightarrow{OP}=3\mathbf{i}+k\mathbf{j}$ and $|\overrightarrow{OP}|=\sqrt{34}$. Find the possible values of $k$. (3 marks)

5

The method

  1. Write the vector

    Get the vector in component form, subtracting position vectors if needed.

  2. Square the length

    Write $|\mathbf{v}|^2$ as the sum of the squares of the components.

  3. Square the given value

    Square the given length, so $\sqrt{34}$ becomes $34$.

  4. Solve

    Expand the brackets and solve for the unknown.

  5. Choose values

    Use any condition given; otherwise give all the values.

Do not lose marks here

  • ✗
    Squaring part

    Square the whole component, sign included: $(-3p)^2=9p^2$.

  • ✗
    Missing root

    A quadratic in the unknown usually gives two values.

What a complete response includes

A method mark for finding the needed vector, a method mark for a correct Pythagoras (or cosine rule) expression set equal to the squared length, a method mark for solving, and accuracy marks for the correct values. One-mark parts simply want the correct length.

How long is a vector? Magnitudes and finding unknowns · January 2020 · Paper 2 · Question 4 · part (b) · 3 marks

The points $A$, $B$, $C$ and $D$ are the vertices of a quadrilateral $ABCD$ such that $\overrightarrow{AB}=7\mathbf{i}+p\mathbf{j}$, $\overrightarrow{AC}=11\mathbf{i}-p\mathbf{j}$ and $\overrightarrow{AD}=4\mathbf{i}-2p\mathbf{j}$. (b) Given that $|\overrightarrow{BD}|=3\sqrt{10}$, find the possible values of $p$. (3 marks)

Worked explanation

  1. $\overrightarrow{BD}=\overrightarrow{AD}-\overrightarrow{AB}=(4\mathbf{i}-2p\mathbf{j})-(7\mathbf{i}+p\mathbf{j})=-3\mathbf{i}-3p\mathbf{j}$
  2. $|\overrightarrow{BD}|^2=(-3)^2+(-3p)^2=9+9p^2$
  3. $9+9p^2=(3\sqrt{10})^2=90$
  4. $9p^2=81\Rightarrow p^2=9$
  5. $p=3$ or $p=-3$
Model answer · written by olevels.com, not an official Pearson mark scheme

$p=3$ or $p=-3$

How the marks are earned

A method mark for finding $\overrightarrow{BD}$ correctly, a method mark for setting $9+9p^2$ equal to $90$ (the squared length), and an accuracy mark for both values $p=\pm 3$.

Calculation check

  • 4-7 = -3
  • -2 × 3-3 = -9
  • (-3) × × 2+(-3 × 3) × × 2 = 90
  • 3 × × 2 × 10 = 90
  • (-3) × × 2+(-3 × (-3)) × × 2 = 90
