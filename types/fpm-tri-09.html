Using the sine rule, including the two-answer case

Calculation

The sine rule $\frac{a}{\sin A} = \frac{b}{\sin B}$ pairs each side with the angle opposite it. A sine value gives an acute and an obtuse angle, so check which one fits.

5

The method

  1. Pair sides with angles

    Match each side with the angle opposite it before writing the sine rule.

  2. Find the unknown sine

    Use $\frac{\sin B}{b} = \frac{\sin A}{a}$ and find $B$ with $\sin^{-1}$.

  3. Check for a second angle

    If $B$ is acute, $180^\circ - B$ also has this sine.

  4. Use the angle sum

    Find the third angle, then apply the sine rule again for the side asked for.

Do not lose marks here

  • ✗
    Only the acute angle

    The calculator gives the acute angle; the question may need the obtuse one.

  • ✗
    Wrong pairing

    A side must be paired with the angle opposite it.

Triangle $ABC$ has $AC = 10$ cm, angle $CAB = 25^\circ$ and $BC = 7$ cm. Given that angle $ABC$ is obtuse, find, in cm to one decimal place, the length of $AB$.

Worked explanation

  1. $BC = 7$ is opposite $A = 25^\circ$; $AC = 10$ is opposite $B$.
  2. $\frac{\sin B}{10} = \frac{\sin 25^\circ}{7} \Rightarrow \sin B = \frac{10\sin 25^\circ}{7} = 0.6037$
  3. Acute value $37.14^\circ$; $B$ is obtuse so $B = 180^\circ - 37.14^\circ = 142.86^\circ$
  4. $C = 180^\circ - 25^\circ - 142.86^\circ = 12.14^\circ$
  5. $\frac{AB}{\sin C} = \frac{7}{\sin 25^\circ} \Rightarrow AB = \frac{7\sin 12.14^\circ}{\sin 25^\circ} = \frac{7 \times 0.2103}{0.4226} = 3.48$
  6. $AB = 3.5$ cm (1 d.p.)
Model answer · written by olevels.com, not an official Pearson mark scheme

AB = 3.5 cm

How the marks are earned

A method mark for the sine-rule statement for angle B, a method mark for taking 180 degrees minus the acute value, a method mark for the third angle, a method mark for the sine rule for AB, and the accuracy mark for 3.5.
