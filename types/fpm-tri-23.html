Proving identities with double-angle and addition formulae

Written

To prove an identity, start from one side, usually the more complicated one, and change it with known formulae until it equals the other side exactly.

Why

The calculation

$\cos 2A = 1 - 2\sin^2 A = 2\cos^2 A - 1$

$\sin 2A = 2\sin A\cos A$ and $\sin^2 A + \cos^2 A = 1$

Tap a part to see what it means and how to find it.

  • Working on both sides at once: change one side only
  • Starting from the answer and working back

Try itProve $\frac{\sin 2A}{1 + \cos 2A} \equiv \tan A$.

  1. $1 + \cos 2A = 1 + 2\cos^2 A - 1 = 2\cos^2 A$
  2. $\frac{2\sin A\cos A}{2\cos^2 A} = \frac{\sin A}{\cos A} = \tan A$

5

The method

  1. Choose a side

    Start with the more complicated side.

  2. Swap in formulae

    Replace double angles or sums using the formula sheet facts.

  3. Simplify

    Cancel common factors and use $\sin^2 A + \cos^2 A = 1$.

  4. Finish

    Reach the other side exactly and write = RHS.

Do not lose marks here

  • ✗
    Wrong cos 2A form

    Pick the form that cancels the 1.

  • ✗
    Skipped steps

    In a proof every line must be written.

What a complete response includes

Method marks for each correct substitution (expanding, replacing sin^2, cos^2 and sin cos, or the compound angle), and an accuracy mark for a complete, clear chain to the printed result.

(b) Show that $(2\sin x - \cos x)(\sin x - 3\cos x) = \frac{1}{2}(\cos 2x - 7\sin 2x + 5)$.

Worked explanation

  1. LHS $= 2\sin^2 x - 6\sin x\cos x - \sin x\cos x + 3\cos^2 x = 2\sin^2 x - 7\sin x\cos x + 3\cos^2 x$
  2. Substitute $\sin^2 x = \frac{1 - \cos 2x}{2}$, $\cos^2 x = \frac{1 + \cos 2x}{2}$, $\sin x\cos x = \frac{1}{2}\sin 2x$:
  3. $= (1 - \cos 2x) - \frac{7}{2}\sin 2x + \frac{3}{2}(1 + \cos 2x)$
  4. $= \frac{5}{2} + \frac{1}{2}\cos 2x - \frac{7}{2}\sin 2x$
  5. $= \frac{1}{2}(\cos 2x - 7\sin 2x + 5)$ = RHS
Model answer · written by olevels.com, not an official Pearson mark scheme

$(2\sin x - \cos x)(\sin x - 3\cos x) = \frac{1}{2}(\cos 2x - 7\sin 2x + 5)$

How the marks are earned

A method mark for expanding the product, method marks for each correct double-angle substitution (sin^2, cos^2 and sin cos), and an accuracy mark for the complete chain to the given form.
