Finding the unknown letters in a rational curve

Working backwards from given asymptotes and intercepts to find the unknown letters in y = (ax + b)/(cx + d).

Knowledge card

Finding the unknown letters in a rational curve

Calculation

To find unknown constants in $y = \frac{ax + b}{cx + d}$, use each feature in turn: the vertical asymptote fixes $d$, the horizontal asymptote gives $a$ over $c$, and an intercept gives $b$.

1

Work back from the features

Decide first, then tap the ? to check.

3 features to find

Which feature gives each constant?

  1. Ratio of x-coefficients
  2. Zero denominator
  3. Use the y-intercept

Ratio of x-coefficients

Working
$y \to \frac{a}{c}$, so $\frac{a}{1} = 3$.

Zero denominator

Trap
$x = 2$ makes $x + d = 0$, so $d = -2$, not $+2$.

Use the y-intercept

Why
At $x = 0$: $y = \frac{b}{d}$, so $\frac{b}{-2} = -1$.
0 of 3 found

2 features to find

Which feature gives $b$ this time?

  1. Sign of the asymptote
  2. Numerator is zero there

Sign of the asymptote

Trap
$3 + d = 0$ gives $d = -3$: the sign flips.

Numerator is zero there

Why
At $(-1, 0)$ the numerator $ax + b$ must be $0$.
0 of 2 found
2

The calculation

$x = -\frac{d}{c}$ (vertical), $y = \frac{a}{c}$ (horizontal), $\left(0, \frac{b}{d}\right)$ (y-intercept)

  • Sign of $d$: $x = 2$ gives $cx + d = 0$, so $d = -2c$
  • Not substituting the answers back into the final equation

Try it$y = \frac{ax + b}{x + d}$ has vertical asymptote $x = 1$, horizontal asymptote $y = 2$ and crosses the $y$-axis at $(0, 3)$. Find $a$, $b$ and $d$.

  1. Horizontal: $a = 2$ (with $c = 1$)
  2. Vertical: $1 + d = 0$, so $d = -1$; then $\frac{b}{-1} = 3$, so $b = -3$

5

The method

  1. List the features

    Each asymptote or intercept gives one equation.

  2. Use c first

    Use the given value of c in each equation.

  3. Vertical gives d

    Set the denominator to zero at the asymptote value.

  4. Horizontal gives a

    $a \div c$ is the horizontal asymptote value.

  5. Intercept gives b

    Substitute the point, then check the final equation.

Do not lose marks here

  • ✗
    Sign of d

    The asymptote $x = k$ means $x - k$ in the denominator when $c = 1$.

  • ✗
    Wrong intercept

    The $y$-intercept uses $x = 0$; an $x$-intercept sets the numerator to zero.

Finding the unknown letters in a rational curve · November 2021 · Paper 2 · Question 3 · part (b) · 2 marks

A curve has equation $y = \frac{a - bx}{cx - d}$, $x \neq \frac{d}{c}$, where $a$, $c$ and $d$ are prime numbers and $b$ is an integer. The curve crosses the $x$-axis at the point $\left(\frac{5}{4}, 0\right)$. Find the value of $a$ and the value of $b$.

Figures check

After your attempt, see the full worked explanation

Worked explanation

  1. On the $x$-axis $y = 0$, so the numerator is zero at $x = \frac{5}{4}$: $a - b\left(\frac{5}{4}\right) = 0$
  2. Multiply by 4: $4a - 5b = 0$, so $4a = 5b$
  3. $5$ divides $4a$ and has no factor in common with $4$, so $5$ divides $a$; since $a$ is prime, $a = 5$
  4. Then $4(5) = 5b$, so $b = 4$ (an integer, as required)
  5. Check: $5 - 4\left(\frac{5}{4}\right) = 5 - 5 = 0$
Model answer · written by olevels.com, not an official Pearson mark scheme

$a = 5$, $b = 4$

How the marks are earned

A method mark for using the $x$-intercept to set the numerator to zero, giving $4a = 5b$ (or equivalent), and an accuracy mark for both $a = 5$ and $b = 4$.

Calculation check

  • 5-4 × (5 ÷ 4) = 0.0
  • 4 × 5 = 20
  • 5 × 4 = 20
