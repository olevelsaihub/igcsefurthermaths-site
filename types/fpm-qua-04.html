Reading the maximum or minimum from completed-square form

Calculation

A square is never negative, so $a(x+p)^2+q$ with $a>0$ has a least value $q$ at $x=-p$. A minus sign in front gives a greatest value instead.

Which feature gives the least value?

  1. Plus sign: a least value
  2. The x-value is −p
  3. The value is the constant

Plus sign: a least value

Why
A square is never negative, so adding it can only raise the value above $-8$.

The x-value is −p

Working
$x-5=0$ gives $x=5$.
Trap
Writing $x=-5$ is the usual slip.

The value is the constant

Scores
$-8$ is the value, when the square is zero.

3 features to find

Use the least value of $f$ to find the greatest value of $\frac{1}{f}$.

  1. Reciprocal flips the value
  2. Least f gives greatest 1/f
  3. Same x-value

Reciprocal flips the value

Why
A larger denominator gives a smaller fraction.

Least f gives greatest 1/f

Working
Since $f\ge 4$, we get $\frac{1}{f}\le\frac{1}{4}$.

Same x-value

Trap
Do not give $f=4$ as the answer for $\frac{1}{f}$.

The calculation

$a(x+p)^2+q$ has turning point $(-p,\,q)$

$a>0$, plus square: least value $q$; $q-a(x+p)^2$: greatest value $q$.

Tap a part to see what it means and how to find it.

  • Giving $x=p$ instead of $x=-p$
  • Calling the value a greatest value when the square is added

Try itFind the least value of $2(x-5)^2-8$ and the $x$ where it occurs.

  1. $2(x-5)^2\ge 0$, so the expression is at least $-8$
  2. Least value $-8$, when $x-5=0$, so $x=5$

The method

  1. Complete the square

    Write the expression as $(x+p)^2+q$ or $q-a(x+p)^2$.

  2. Read the sign

    A plus square gives a least value; a minus square gives a greatest value.

  3. Set the bracket to zero

    The square is zero when $x+p=0$, so $x=-p$.

  4. Read off the value

    The value is $q$, the constant outside the square.

Do not lose marks here

  • ✗
    Sign of x

    It is $x=-p$, not $x=p$.

  • ✗
    Maximum or minimum

    Check the sign in front of the square before naming the value.

$f(x)=x^2-9x+14$. Given that $f(x)$ can be written in the form $(x+a)^2+b$, hence, or otherwise, find (i) the minimum value of $f(x)$ (ii) the value of $x$ for which this minimum occurs. (2 marks)

Worked explanation

  1. Complete the square (part (a)): $x^2-9x+14=\left(x-\frac{9}{2}\right)^2-\frac{81}{4}+14=\left(x-\frac{9}{2}\right)^2-\frac{25}{4}$
  2. $\left(x-\frac{9}{2}\right)^2\ge 0$, so $f(x)\ge -\frac{25}{4}$
  3. The minimum happens when $x-\frac{9}{2}=0$, i.e. $x=\frac{9}{2}$
  4. Check: $f(4.5)=20.25-40.5+14=-6.25=-\frac{25}{4}$
Model answer · written by olevels.com, not an official Pearson mark scheme

(i) minimum value $-\frac{25}{4}$ (ii) at $x=\frac{9}{2}$

How the marks are earned

One mark for the minimum value $-\frac{25}{4}$ and one for $x=\frac{9}{2}$, each allowed to follow through from the $a$ and $b$ found in part (a).

Calculation check

  • 14-(9 ÷ 2) × × 2 = -6.25
  • 4.5 × × 2-9 × 4.5+14 = -6.25
