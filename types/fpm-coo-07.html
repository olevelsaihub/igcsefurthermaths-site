The calculation

$y = m_1x + c_1$ and $y = m_2x + c_2$ meet where $m_1x + c_1 = m_2x + c_2$

Parallel lines (equal gradients) never meet.

Tap a part to see what it means and how to find it.

  • Stopping at x and forgetting y
  • Substituting into the wrong equation

Try itFind where $y = 2x + 1$ meets $y = -x + 7$.

  1. $2x + 1 = -x + 7$, so $3x = 6$ and $x = 2$
  2. $y = 2(2) + 1 = 5$, so the point is $(2, 5)$

The method

  1. Write both equations

    Find each line equation if it is not given.

  2. Eliminate one variable

    Substitute one equation into the other, or add or subtract multiples.

  3. Solve

    Find the first coordinate.

  4. Substitute back

    Find the second coordinate and write the point as a pair.

Do not lose marks here

  • ✗
    Half a point

    Give both coordinates in brackets.

  • ✗
    Wrong equation for y

    Find y from a line, and check it in the other line.

Where two lines meet · January 2023 · Paper 1 · Question 2 · part (b) · 3 marks

The point $A$ has coordinates $(-5, 3)$, the point $B$ has coordinates $(4, 0)$ and the point $C$ has coordinates $(-1, 5)$. The line $l$ passes through $C$ and is perpendicular to $AB$. The line $l$ intersects $AB$ at the point $D$. (b) Show that the coordinates of $D$ are $(-2, 2)$.

Worked explanation

  1. Gradient of $AB = \frac{0 - 3}{4 - (-5)} = -\frac{3}{9} = -\frac{1}{3}$
  2. Equation of $AB$: $y - 0 = -\frac{1}{3}(x - 4) \Rightarrow 3y = -x + 4 \Rightarrow x + 3y - 4 = 0$
  3. From part (a), $l$ has gradient $3$ through $C(-1, 5)$: $y - 5 = 3(x + 1) \Rightarrow y = 3x + 8$
  4. Substitute into $AB$: $x + 3(3x + 8) - 4 = 0 \Rightarrow 10x + 20 = 0 \Rightarrow x = -2$
  5. $y = 3(-2) + 8 = 2$
  6. So $D$ is $(-2, 2)$.
Model answer · written by olevels.com, not an official Pearson mark scheme

$D = (-2, 2)$, as required.

How the marks are earned

A method mark for the equation of $AB$, a method mark for solving it simultaneously with the equation of $l$ to reach one coordinate, and an accuracy mark for both coordinates reached by a correct method.

Calculation check

  • -2+3 × 2-4 = 0
  • 3 × (-2)+8 = 2
  • round((0-3) ÷ (4-(-5)),6) = -0.333333
