The calculation

$\sin u = k \Rightarrow u = \sin^{-1}k$ or $180^\circ - \sin^{-1}k$, plus $360^\circ n$

$\cos u = k \Rightarrow u = \pm\cos^{-1}k + 360^\circ n$, and $\tan u = k \Rightarrow u = \tan^{-1}k + 180^\circ n$

5

The method

  1. Isolate the ratio

    Rearrange so one trig ratio of $u = 2x + 30$ equals a constant.

  2. Transform the interval

    For $0 \le x < 180$, the angle $u$ lies in $30 \le u < 390$.

  3. Find all solutions for u

    Use the principal value and the symmetry of the graph within the interval.

  4. Undo the shift and multiple

    Solve $u = 2x + 30$ for $x$ and check each root is in $0 \le x < 180$.

Do not lose marks here

  • ✗
    Interval not changed

    Using $0$ to $180$ for $u$ gives the wrong roots.

  • ✗
    Solutions outside range

    Remove any answer that falls outside the original interval.

(a) Solve, to the nearest integer, the equation $\sin(2x - 75)^\circ = -0.515$ for $0 \le x < 180$.

Worked explanation

  1. Let $u = 2x - 75$. Since $0 \le x < 180$: $-75 \le u < 285$.
  2. Principal value: $u = \sin^{-1}(-0.515) = -30.997^\circ$, which is in the interval.
  3. Second value: $u = 180^\circ - (-30.997^\circ) = 210.997^\circ$, in the interval. ($360^\circ - 30.997^\circ = 329.0^\circ$ is too big.)
  4. $2x - 75 = -30.997 \Rightarrow x = 22.00$
  5. $2x - 75 = 210.997 \Rightarrow x = 143.00$
Model answer · written by olevels.com, not an official Pearson mark scheme

$x = 22$ or $x = 143$

How the marks are earned

A method mark for the principal value -31.0 (or 31.0), a method mark for a second value in the transformed interval and for converting back to x, and an accuracy mark for both 22 and 143 with no extra answers.

Calculation check

  • round(30.997454986280143,3) = 30.997
  • round((75-30.997454986280143) ÷ 2,2) = 22.0
  • round((180+30.997454986280143+75) ÷ 2,2) = 143.0
  • 360-30.997454986280143 = 329.00254501371984
