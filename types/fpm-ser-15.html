Knowledge card

Series made of logarithms

Written
  • $\ln(ab) = \ln a + \ln b$ and $\ln a^k = k\ln a$ (the same for any base).
  • $\ln 4 = \ln 2^2 = 2\ln 2$.
  • If $u_n = \ln a + (n-1)\ln b$ the series is arithmetic with first term $\ln a$ and common difference $\ln b$.
  • Taking logs of a geometric term $ar^{n-1}$ gives $\log a + (n-1)\log r$, which is linear in $n$.
  • $\ln(a + b)$ is NOT $\ln a + \ln b$.

Before you begin

  • Laws of logarithms.
  • Arithmetic series formulas.
  • Index laws.
1

The method

  1. Write the first term and the common difference (or the general term) using log laws.

    Why: Log laws turn products and powers into sums and multiples.

  2. Treat $\ln 2$ (or $\ln a$, $\ln b$) like an ordinary number while using the series formulas.

    Why: The arithmetic series formulas work the same with log coefficients.

  3. Simplify, then rewrite logs in the base or form asked (e.g. replace ln 4 by 2 ln 2).

    Why: The final form usually has a single log factor.

  4. Solve any simultaneous equations for the log values and convert back to numbers.

    Why: e.g. $\ln b = \ln 4$ gives $b = 4$.

Do not lose marks here

  • ✗
    Using $\ln(a + b) = \ln a + \ln b$.
  • ✗
    Forgetting that $\ln 4 = 2 \ln 2$ when the answer is in terms of $\ln 2$.
  • ✗
    Getting the first term wrong by substituting n = 0 instead of n = 1.
  • ✗
    Algebra slips when expanding with a log factor.

Series made of logarithms · June 2021 · Paper 1 · Question 4 · part (whole) · 5 marks

The $n$th term of an arithmetic series is $u_n$ where $u_n = (n + 1)\ln 4$. Given that the sum of the first $n$ terms of the series is $S_n$, show that $S_n = \ln 2\,(n^2 + an)$ where $a$ is an integer whose value is to be found.

Question restated by olevels.com from the original paper; the original is below.

View full original question and diagrams
After your attempt, see the full worked explanation

Worked explanation

  1. First term $u_1 = 2\ln 4$; $u_2 = 3\ln 4$, so the common difference is $\ln 4$
  2. $S_n = \frac{n}{2}[2(2\ln 4) + (n - 1)\ln 4] = \frac{n}{2}(n + 3)\ln 4$
  3. $\ln 4 = 2\ln 2$, so $S_n = \frac{n}{2}(n + 3)(2\ln 2) = n(n + 3)\ln 2$
  4. $S_n = \ln 2\,(n^2 + 3n)$, so $a = 3$
Model answer · written by olevels.com, not an official Pearson mark scheme

$S_n = \ln 2\,(n^2 + 3n)$, $a = 3$

How the marks are earned

Method marks for the first term 2 ln 4 and common difference ln 4, for using the arithmetic sum formula, and for converting ln 4 to 2 ln 2; accuracy marks for the simplified form and a = 3.

Calculation check

  • 2 × (2+3+4) = 18
  • 3 × × 2+3 × 3 = 18
