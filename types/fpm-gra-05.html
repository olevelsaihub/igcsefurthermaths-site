Knowledge card

Where a rational curve crosses the axes

Calculation

To find where $y = \frac{ax + b}{cx + d}$ crosses the axes: put $x = 0$ for the $y$-intercept $\left(0, \frac{b}{d}\right)$, and make the numerator zero for the $x$-intercept.

Which axis, which number

3 steps to find

Which line finds each intercept?

  1. Keep the fraction exact
  2. Use the numerator
  3. Denominator gives asymptote

Keep the fraction exact

Why
Give $-\frac{6}{5}$ exactly; a wrong decimal such as $-1.23$ loses the mark.

Use the numerator

Why
A fraction is zero only when its top is zero, so solve $3x - 6 = 0$.

Denominator gives asymptote

Trap
$2x + 5 = 0$ gives $x = -\frac{5}{2}$, an asymptote, not a point.
0 of 3 found

2 steps to find

Which axis does each line test?

  1. Negative denominator
  2. Give a coordinate pair

Negative denominator

Working
$0 - 1 = -1$, so $y = \frac{4}{-1} = -4$.

Give a coordinate pair

Why
A value alone, such as $-4$, is not a point: write $(0, -4)$.
0 of 2 found
2

The calculation

$y = \frac{ax + b}{cx + d}$: $y$-intercept $\left(0, \frac{b}{d}\right)$, $x$-intercept $\left(-\frac{b}{a}, 0\right)$

Tap a part to see what it means and how to find it.

  • Setting the denominator to zero: that gives the asymptote, not an intercept
  • One coordinate only: each intercept is a pair $(x, y)$

Try itFind the intercepts of $y = \frac{2x + 3}{x - 5}$.

  1. $x = 0$: $y = \frac{3}{-5} = -\frac{3}{5}$, so $\left(0, -\frac{3}{5}\right)$
  2. $y = 0$: $2x + 3 = 0$, so $\left(-\frac{3}{2}, 0\right)$

5

The method

  1. Choose the axis

    The $y$-axis has $x = 0$; the $x$-axis has $y = 0$.

  2. Y-intercept

    Put $x = 0$ and simplify the fraction.

  3. X-intercept

    A fraction is zero only when its top line is zero.

  4. Write pairs

    Give each point as $(x, y)$ with exact fractions.

Do not lose marks here

  • ✗
    Denominator confusion

    Setting the bottom to zero gives an asymptote.

  • ✗
    Single coordinate

    Answers are points, so both values are needed.

Where a rational curve crosses the axes · November 2021 · Paper 2 · Question 3 · part (c) · 2 marks

The curve with equation $y = \frac{a - bx}{cx - d}$, $x \neq \frac{d}{c}$, where $a$, $c$, $d$ are prime and $b$ is an integer, has vertical asymptote $x = \frac{3}{2}$ and crosses the $x$-axis at $\left(\frac{5}{4}, 0\right)$. The curve crosses the $y$-axis at the point $(0, p)$, where $p$ is a rational number. Find the value of $p$.

Worked explanation

  1. From the asymptote: $cx - d = 0$ at $x = \frac{3}{2}$, so $\frac{d}{c} = \frac{3}{2}$; with $c$, $d$ prime, $c = 2$, $d = 3$
  2. From the $x$-intercept: $a - b\left(\frac{5}{4}\right) = 0 \Rightarrow 4a = 5b$; $a$ prime gives $a = 5$, $b = 4$
  3. So $y = \frac{5 - 4x}{2x - 3}$
  4. At the $y$-axis $x = 0$: $p = \frac{5 - 0}{0 - 3} = -\frac{5}{3}$
Model answer · written by olevels.com, not an official Pearson mark scheme

$p = -\frac{5}{3}$

How the marks are earned

A method mark for substituting $x = 0$ into the curve with the constants found earlier, and an accuracy mark for $p = -\frac{5}{3}$.

Calculation check

  • 5 ÷ (0-3) = -1.6666666666666667
  • 5-4 × (5 ÷ 4) = 0.0
  • -5 ÷ 3 = -1.6666666666666667
