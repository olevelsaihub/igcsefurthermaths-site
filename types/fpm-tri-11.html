Knowledge card

Area of a triangle using half ab sin C

Calculation

Area $= \frac{1}{2}ab\sin C$ uses the angle between the two sides. Solving backwards for $\sin C$ can give an acute and an obtuse angle.

The calculation

$\text{Area} = \frac{1}{2}ab\sin C$, where $C$ lies between sides $a$ and $b$

Backwards: $\sin C = \frac{2 \times \text{Area}}{ab}$

Tap a part to see what it means and how to find it.

  • Using an angle that is not between the two sides
  • Forgetting the $\frac{1}{2}$ when solving for $\sin C$

Try itTriangle with $a = 4$, $b = 5$ and area $5$. Find $\sin C$.

  1. $5 = \frac{1}{2}(4)(5)\sin C = 10\sin C$
  2. $\sin C = \frac{1}{2}$

5

The method

  1. Find the included angle

    Check the angle lies between the two sides given.

  2. Write the area formula

    Use $\text{Area} = \frac{1}{2}ab\sin C$, or rearrange it for $\sin C$.

  3. Solve for the sine

    Keep exact values where asked, such as $\sin 30^\circ = \frac{1}{2}$.

  4. Find both angles

    Use $\sin^{-1}$ for the acute angle, then $180^\circ$ minus it for the obtuse one.

Do not lose marks here

  • ✗
    Missing the second triangle

    A sine value can give two valid angles in a triangle.

  • ✗
    Forgetting the half

    The $\frac{1}{2}$ must stay when the formula is rearranged.

In triangle $ABC$, $AB = 3x$ cm, $AC = 2x$ cm and $BC = 4x$ cm. The area of triangle $ABC$ is $50$ cm$^2$. Find, to 2 decimal places, the value of $x$.

Worked explanation

  1. Angle $A$ is between $AB = 3x$ and $AC = 2x$; the opposite side is $BC = 4x$.
  2. $\cos A = \frac{(3x)^2 + (2x)^2 - (4x)^2}{2(3x)(2x)} = \frac{9 + 4 - 16}{12} = -\frac{1}{4}$
  3. $\sin A = \sqrt{1 - \frac{1}{16}} = \frac{\sqrt{15}}{4}$ (positive, since $A$ is an angle of a triangle)
  4. Area $= \frac{1}{2}(3x)(2x)\left(\frac{\sqrt{15}}{4}\right) = \frac{3\sqrt{15}}{4}x^2 = 50$
  5. $x^2 = \frac{200}{3\sqrt{15}} = 17.213$
  6. $x = 4.1489$, so $x = 4.15$ (2 d.p.)
Model answer · written by olevels.com, not an official Pearson mark scheme

x = 4.15

How the marks are earned

A method mark for using the cosine rule to find an angle, a method mark for half ab sin C with that angle set equal to 50, a method mark for solving for x, and the accuracy mark for 4.15.

Calculation check

  • (9+4-16) ÷ 12 = -0.25
  • round(3 × 15 × × 0.5 ÷ 4,5) = 2.90474
  • round((4.5 × 2.5 × 1.5 × 0.5) × × 0.5,5) = 2.90474
  • round(200 ÷ (3 × 15 × × 0.5),3) = 17.213
  • round((200 ÷ (3 × 15 × × 0.5)) × × 0.5,2) = 4.15
