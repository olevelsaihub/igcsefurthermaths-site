The calculation

$\sin 2A = 2\sin A\cos A$, $\quad \cos 2A = 2\cos^2 A - 1 = 1 - 2\sin^2 A$

$\tan 2A = \frac{2\tan A}{1 - \tan^2 A}$

5

The method

  1. Write the addition formula

    Start from $\cos(A + B) = \cos A\cos B - \sin A\sin B$.

  2. Put B = A

    Replace $B$ by $A$, so that $A + B = 2A$.

  3. Use the identity

    Replace $\sin^2 A$ using $\sin^2 A = 1 - \cos^2 A$.

  4. Simplify to the form asked

    Collect terms until you reach $2\cos^2 A - 1$.

Do not lose marks here

  • ✗
    Sign error

    $\cos(A + B)$ has a minus between the two products.

  • ✗
    Writing 2 sin A

    $\sin 2A = 2\sin A\cos A$, not $2\sin A$.

Worked explanation

  1. $\cos(A + B) = \cos A\cos B - \sin A\sin B$
  2. Put $A = B = x$: $\cos 2x = \cos x\cos x - \sin x\sin x = \cos^2 x - \sin^2 x$
  3. Use $\cos^2 x = 1 - \sin^2 x$: $\cos 2x = (1 - \sin^2 x) - \sin^2 x$
  4. $\cos 2x = 1 - 2\sin^2 x$
Model answer · written by olevels.com, not an official Pearson mark scheme

$\cos 2x = 1 - 2\sin^2 x$

How the marks are earned

A method mark for using cos(A + B) with both angles equal to x, a method mark for replacing cos^2 x with 1 - sin^2 x, and an accuracy mark for the complete result.
