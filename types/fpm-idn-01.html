Linear inequalities and the 'both' overlap

Solving a single inequality in which x appears only to the first power, including one with surd coefficients.

Type 3 3 Identities and inequalities FPM-IDN-01

★★☆☆☆ · 7 of 44 eligible examination papers, 2019–2025. Difficulty: Medium.

Usually Question 1 or 2 of a paper: 'Find the set of values of x for which' followed by (a) an inequality where x appears only as x (not x squared), (b) a quadratic inequality and (c) 'both ... and ...'. The surd version says 'Without using a calculator, solve the inequality' and asks for a rationalised denominator.

Knowledge card

Linear inequalities and the 'both' overlap

Written
  • An inequality is solved like an equation: you may add or subtract the same thing on both sides, and multiply or divide both sides by the same positive number.
  • If you multiply or divide both sides by a negative number the inequality sign reverses, e.g. $-3x<6 \Rightarrow x>-2$.
  • $<$ and $>$ are strict (the end value is not included); $\leqslant$ and $\geqslant$ include the end value.
  • A surd coefficient such as $(\sqrt{5}-3)$ is a number: decide its sign before dividing (here $\sqrt{5}-3<0$, so the sign reverses), then rationalise, e.g. $\frac{1}{\sqrt{5}-3}=\frac{\sqrt{5}+3}{(\sqrt{5}-3)(\sqrt{5}+3)}=\frac{\sqrt{5}+3}{-4}$.
  • 'Both A and B' means the overlap (intersection) of the two solution sets: the values that are in A and also in B.
  • A number line showing each solution set makes the overlap easy to see.

  • Solving linear equations

The method

  1. Expand any brackets, e.g. $2(3x-1)=6x-2$.

    Why: You cannot collect the x terms until they are all out of brackets.

  2. Collect the $x$ terms on one side and the numbers on the other by adding or subtracting.

    Why: Adding or subtracting never changes the direction of the sign, so this step is always safe.

  3. Divide by the coefficient of $x$. If it is negative, reverse the sign. If it is a surd expression, check its sign first.

    Why: Dividing by a negative number swaps which side is bigger, so the sign must flip.

  4. For a surd answer, rationalise the denominator by multiplying top and bottom by the conjugate.

    Why: The question asks for an exact answer with a rationalised denominator.

  5. For a 'both' part, draw both solution sets on one number line and write down only the part covered twice.

    Why: 'Both' means each inequality must be true at the same time, which is the overlap, not the combined set.

Do not lose marks here

  • ✗
    Forgetting to reverse the sign after dividing by a negative number (or a negative surd expression).
  • ✗
    Expanding brackets wrongly, e.g. $2(3x-1)=6x-1$.
  • ✗
    Giving the union (either set) instead of the overlap in a 'both' part.
  • ✗
    Leaving the surd answer with an irrational denominator or as a decimal.
  • ✗
    Writing the answer as an equation, e.g. $x=\frac{2}{3}$, instead of an inequality.

How each command word is answered

Command wordTimes askedWhat to write
Find14Give the set of values as an inequality in $x$, such as $x<\frac{2}{3}$; a fraction is fine. For 'both', give one interval such as $-\frac{1}{3}<x<\frac{2}{3}$.
Solve1Show every line, especially the step where you divide by the surd coefficient and the rationalising step; give the exact answer with a rationalised denominator, no decimals.

Now see it used on a real past-paper question

What a complete response includes

The simple linear part is worth 1 or 2 marks: a method mark for collecting terms correctly (when 2 marks) and an accuracy mark for the correct inequality. The surd version (4 marks) gives method marks for collecting and factorising out x, for dividing and for rationalising, then accuracy for the exact answer with the correct sign. The 'both' part is a single mark for the correct overlap, usually allowed to follow from the student's earlier answers.

Linear inequalities and the 'both' overlap · January 2023 · Paper 2 · Question 1 · part (a) · 2 marks

Find the set of values of $x$ for which $2(3x-1)<4-3x$.

Question restated by olevels.com from the original paper; the original is below.

View full original question and diagrams
After your attempt, see the full worked explanation

Worked explanation

  1. $2(3x-1)<4-3x$
  2. $6x-2<4-3x$ (expand the bracket)
  3. $6x+3x<4+2$ (add $3x$ and add $2$ to both sides)
  4. $9x<6$
  5. $x<\frac{6}{9}=\frac{2}{3}$ (divide by $9$, a positive number, so the sign stays the same)
  6. Check with $x=0$: $2(0-1)=-2<4$, true, and $0<\frac{2}{3}$ as expected.
Model answer · written by olevels.com, not an official Pearson mark scheme

$x<\frac{2}{3}$

How the marks are earned

One method mark for correctly collecting the terms to reach $9x<6$ (or equivalent), and one accuracy mark for $x<\frac{2}{3}$. In part (c) of the same question this combines with $-\frac{1}{3}<x<3$ from part (b) to give the overlap $-\frac{1}{3}<x<\frac{2}{3}$.

Calculation check

  • 6 ÷ 9 = 0.6666666666666666
  • 2 × (3 × (2 ÷ 3)-1) = 2
  • 4-3 × (2 ÷ 3) = 2
  • 2 × (3 × 0-1) = -2
