What a log means: reading values and switching to index form

Using the definition of a logarithm to read off a value or to turn one log statement straight into a power.

Type 1 1 Logarithms, indices and surds FPM-LOG-01

★☆☆☆☆ · 4 of 44 eligible examination papers, 2019–2025. Difficulty: Easy.

A short part (1 or 2 marks) with a single log and no laws to combine: 'Write down the value of $\log_2 16$', 'Find $a$ such that $\log_a 8 = \ldots$', or 'Given $\log_p x = 3$, express $x$ in terms of $p$'. It is often part (a) of a longer log question.

Knowledge card

What a log means: reading values and switching to index form

Calculation

A log $\log_a b = c$ is the power $a^c = b$. Write the log in index form to read its value, or to find the base or the number.

Which step takes a root?

  2. Take the 4th root

Index form first

Why
$\log_a b = c$ means $a^c = b$: the base is raised to the log value.

Trap

2 steps to find

Which power of 2 gives 1/8?

  1. Write 1/8 as a power
  2. Negative answers are allowed

Write 1/8 as a power

Why
$\frac{1}{8} = \frac{1}{2^3} = 2^{-3}$, so the log value is $-3$.

Negative answers are allowed

Scores
A negative log value is correct here, not an error.

5

The method

  1. Write in index form

    Turn $\log_a b = c$ into $a^c = b$.

  2. Look for the power

    Write the number as a power of the base to read the log value.

  3. Solve for an unknown base

    Use a root: $a^c = b$ gives $a = b^{1/c}$.

  4. Check the conditions

    The base is positive and not 1; the number is positive.

Do not lose marks here

  • ✗
    Swapping base and number

    $\log_a b$ is not $\log_b a$.

  • ✗
    Negative base

    A base must be positive, so take the positive root only.

What a complete response includes

A one-mark 'write down' part earns a B mark for the correct value alone. Two-mark parts give a method mark for correctly writing the index form (or an equivalent power statement) and an accuracy mark for the exact value.

Worked explanation

  1. $\log_p x = 3$
  2. By the definition of a log, the base $p$ raised to the power 3 gives $x$:
  3. $x = p^3$

How the marks are earned

One mark for $x = p^3$; no further working is needed. Check with a sample value: if $p = 2$ then $x = 2^3 = 8$ and $\log_2 8 = 3$, as given.
