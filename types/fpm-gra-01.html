Filling in a table of values

Working out the missing y-values in a table for a given curve (polynomial, reciprocal, exponential, logarithmic or trigonometric) to the stated number of decimal places.

Knowledge card

Filling in a table of values

Calculation
  • Each missing $y$-value comes from substituting that $x$-value into the equation exactly as printed
  • Trigonometric curves in this paper use radians: set the calculator to RAD before you start
  • Change of base: $\log_b x = \frac{\ln x}{\ln b} = \frac{\log_{10} x}{\log_{10} b}$, for logs that are not base 10 or $e$
  • $\log_b 1 = 0$ and $\log_b b = 1$, so some entries come out as exact whole numbers
  • Rounding to 2 decimal places means look at the third decimal place; never just chop the digits off
  • 'Where appropriate' means an exact value such as $4$ or $2.5$ can be written as it is

Before you begin

  • Using a calculator for $\ln$, $\log$, $e^x$ and trig functions
  • Rounding to decimal places
  • Substituting negative numbers and fractions into expressions
  • Radian measure
1

The method

  1. Copy the equation of the curve and check the calculator mode (radians for any sin, cos or tan).

    Why: A degree-mode value for a trig curve is wrong for every entry.

  2. Pick one of the printed values and recompute it yourself.

    Why: If you get the printed answer, you know you have read the equation and set the calculator correctly.

  3. Substitute each missing $x$-value, putting negative values in brackets and using change of base for logs such as $\log_3$.

    Why: Brackets stop sign slips like $-2^2 = -4$ instead of $(-2)^2 = 4$.

  4. Round each answer to the accuracy asked for; keep exact values exact.

    Why: The accuracy mark depends on correct rounding.

  5. Look along the row: do your values fit smoothly between the printed ones?

    Why: A value that jumps out of the pattern is almost always a keying error, and it would spoil the graph too.

Do not lose marks here

  • ✗
    Calculator left in degree mode for a trigonometric curve
  • ✗
    Losing a minus sign when substituting a negative $x$-value (no brackets)
  • ✗
    Using $\log_{10}$ or $\ln$ directly for a base 3 log instead of changing base
  • ✗
    Truncating instead of rounding, e.g. writing $4.14$ as $4.1$ when 2 d.p. is asked, or $3.369$ as $3.36$
  • ✗
    Misreading the equation, such as $\ln(2x+1)$ read as $\ln 2x + 1$

Common mistakes: Inferred, not measured. Inferred from typical examiner credit patterns for this method; not measured student-error statistics.

How each command word is answered

Command wordTimes askedWhat to write
Complete15Write each value in its box in the table, rounded to the stated number of decimal places (exact values may be left exact). No working is needed, but each value must be correct.

Now see it used on a real past-paper question

What a complete response includes

A B-style pair: one mark for at least two (or some) correct values and the second mark for every value correct to the required accuracy. No method marks, so the values themselves must be right.

Filling in a table of values · June 2025 · Paper 2 · Question 7 · part (a) · 2 marks

Complete the table of values for $y = 3 + \log_3(4 - x)$, giving your answers to 2 decimal places. | $x$ | 0 | 0.5 | 1 | 1.5 | 2 | 2.5 | 3 | 3.5 | |---|---|---|---|---|---|---|---|---| | $y$ | 4.26 | | | | 3.63 | | | 2.37 |

After your attempt, see the full worked explanation

Worked explanation

  1. Change of base: $\log_3(4-x) = \frac{\ln(4-x)}{\ln 3}$
  2. Check a printed value: $x = 2$: $3 + \frac{\ln 2}{\ln 3} = 3 + 0.6309 = 3.6309 \approx 3.63$ (matches the table)
  3. $x = 0.5$: $3 + \log_3 3.5 = 3 + 1.1403 = 4.1403 \approx 4.14$
  4. $x = 1$: $3 + \log_3 3 = 3 + 1 = 4$ (exact)
  5. $x = 1.5$: $3 + \log_3 2.5 = 3 + 0.8340 = 3.8340 \approx 3.83$
  6. $x = 2.5$: $3 + \log_3 1.5 = 3 + 0.3691 = 3.3691 \approx 3.37$
  7. $x = 3$: $3 + \log_3 1 = 3 + 0 = 3$ (exact)
  8. Pattern check: $4.26, 4.14, 4, 3.83, 3.63, 3.37, 3, 2.37$ falls steadily and faster near $x = 4$, as a log curve near its asymptote should
Model answer · written by olevels.com, not an official Pearson mark scheme

$x = 0.5$: $4.14$; $x = 1$: $4$; $x = 1.5$: $3.83$; $x = 2.5$: $3.37$; $x = 3$: $3$

How the marks are earned

One mark for some of the missing values correct (typically two of them) and the second for all of them correct to 2 decimal places.

Calculation check

  • round(3 × × 1.1403,2) = 3.5
  • round(3 × × 0.834,2) = 2.5
  • round(3 × × 0.3691,2) = 1.5
  • round(3 × × 0.6309,2) = 2.0
  • round(3 × × (-0.6309),2) = 0.5
  • round(3+1.1403,2) = 4.14
