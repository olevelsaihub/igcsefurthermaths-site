Filling in a table of values

Working out the missing y-values in a table for a given curve (polynomial, reciprocal, exponential, logarithmic or trigonometric) to the stated number of decimal places.

Knowledge card

Filling in a table of values

Calculation

To complete a table of values, substitute each $x$-value into the equation exactly as printed, then round only the final answer to the decimal places asked.

1

Check each entry

Decide first, then tap the ? to check.

3 entries to find

Which entries need a sign or rounding check?

  1. Minus times minus
  2. Read the third decimal
  3. Round, do not chop

Minus times minus

Working
$-3 \times (-1) = +3$, so the row reads $0.5 + 3$.
Trap
Writing $0.5 - 3$ gives the wrong sign.

Read the third decimal

Why
$2.20711\ldots$ has third decimal 7, so it rounds up to $2.21$.

Round, do not chop

Why
$-0.08579\ldots$ rounds to $-0.09$; chopping to $-0.08$ loses the mark.
0 of 3 found

3 entries to find

Which entry is exact, and which needs change of base?

  1. Change of base
  2. Exact whole number
  3. Round the third decimal

Change of base

Working
$\log_5 4 = \frac{\ln 4}{\ln 5} = 0.8614\ldots$
Trap
The calculator has $\log$ (base 10) and $\ln$ only, never $\log_5$.

Exact whole number

Why
$\log_5 5 = 1$ exactly, so $y = 3$ with no rounding.

Round the third decimal

Why
$3.2091\ldots$ has third decimal 9, so it rounds up to $3.21$.
0 of 3 found
2

The calculation

$\log_b x = \frac{\ln x}{\ln b}$

Put the calculator in **RAD** before any $\sin$, $\cos$ or $\tan$ entry.

Tap a part to see what it means and how to find it.

  • Losing a minus sign: $x = -2$ needs brackets, so $(-2)^2 = 4$
  • Chopping digits: $4.146$ to 2 d.p. is $4.15$, not $4.14$

Try itFind $y = 2 + \log_5 3$ to 2 decimal places.

  1. $\log_5 3 = \frac{\ln 3}{\ln 5} = 0.6826\ldots$
  2. $y = 2 + 0.6826\ldots = 2.68$ (to 2 d.p.)

Does it score?

Exam question

Complete the table of values for $y = 1 + \log_2(x + 2)$ at $x = 1$ and $x = 4$, giving $y$ to 2 decimal places. (2 marks)

Decide first: would this answer earn the mark? Then tap it to check.

Tap an answer to see if it earns the mark.

5

The method

  1. Check the mode

    Radians for any trig curve; check the calculator first.

  2. Substitute carefully

    Put each $x$ in brackets, then calculate.

  3. Change base for logs

    Use $\frac{\ln x}{\ln b}$ unless the base is $10$ or $e$.

  4. Round at the end

    Keep full calculator values, then round to the places asked.

  5. Check the pattern

    Values should rise or fall smoothly along the row.

Do not lose marks here

  • ✗
    Degree mode

    Every entry of a trig curve is wrong in degrees.

  • ✗
    Chopping digits

    $4.146$ to 2 d.p. is $4.15$, not $4.14$.

What a complete response includes

A B-style pair: one mark for at least two (or some) correct values and the second mark for every value correct to the required accuracy. No method marks, so the values themselves must be right.

Worked explanation

  1. Change of base: $\log_3(4-x) = \frac{\ln(4-x)}{\ln 3}$
  2. Check a printed value: $x = 2$: $3 + \frac{\ln 2}{\ln 3} = 3 + 0.6309 = 3.6309 \approx 3.63$ (matches the table)
  3. $x = 0.5$: $3 + \log_3 3.5 = 3 + 1.1403 = 4.1403 \approx 4.14$
  4. $x = 1$: $3 + \log_3 3 = 3 + 1 = 4$ (exact)
  5. $x = 1.5$: $3 + \log_3 2.5 = 3 + 0.8340 = 3.8340 \approx 3.83$
  6. $x = 2.5$: $3 + \log_3 1.5 = 3 + 0.3691 = 3.3691 \approx 3.37$
  7. $x = 3$: $3 + \log_3 1 = 3 + 0 = 3$ (exact)
  8. Pattern check: $4.26, 4.14, 4, 3.83, 3.63, 3.37, 3, 2.37$ falls steadily and faster near $x = 4$, as a log curve near its asymptote should
Model answer · written by olevels.com, not an official Pearson mark scheme

$x = 0.5$: $4.14$; $x = 1$: $4$; $x = 1.5$: $3.83$; $x = 2.5$: $3.37$; $x = 3$: $3$

How the marks are earned

One mark for some of the missing values correct (typically two of them) and the second for all of them correct to 2 decimal places.

Calculation check

  • round(3 × × 1.1403,2) = 3.5
  • round(3 × × 0.834,2) = 2.5
  • round(3 × × 0.3691,2) = 1.5
  • round(3 × × 0.6309,2) = 2.0
  • round(3 × × (-0.6309),2) = 0.5
  • round(3+1.1403,2) = 4.14
