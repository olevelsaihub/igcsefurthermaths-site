Idea۔ Dot-to-dot تصویر کا سوچیں۔ پہلے dots آتے ہیں، پھر انہیں join کرتے ہیں۔ Graph بھی ایسا ہی ہے۔ Table کا ہر column ایک point ہے: x کتنا آگے، y کتنا اوپر۔ Dots کو ایک smooth curve سے join کریں، freehand یعنی ہاتھ سے، ruler کے بغیر۔ Ruler سے تیز corners بنتے ہیں جو اصل curve میں نہیں ہوتے۔ سوال میں interval دی جاتی ہے، جیسے صفر سے تین اعشاریہ پانچ تک۔ Curve پہلے point سے شروع ہو کر آخری point پر رک جاتی ہے۔ اس سوال میں لکھا ہوتا ہے: on the grid, draw the graph of this equation۔ آپ اپنی table استعمال کرتے ہیں، points plot کرتے ہیں اور ایک smooth curve بناتے ہیں۔
