Method۔ Step ایک: triangle کا نام لکھیں اور اسے flat بنائیں۔ Step دو: solid میں Pythagoras سے ہر side نکالیں۔ Step تین: angle کے لیے cosine rule استعمال کریں۔ Area کے لیے ایک over دو base ضرب height۔ Step چار: surface area کے لیے ہر face کو ایک بار add کریں۔ Trap: sloping edge کو face کی height سمجھنا، یا بغیر check کیے right angle فرض کرنا۔

Worked Example۔ جنوری دو ہزار بیس۔ ایک تکونے pyramid کی base equilateral A B C ہے، sides آٹھ centimetres۔ Vertex X عین A کے اوپر ہے، اور height نو ہے۔ Angle B X C ایک decimal place تک نکالیں۔ تین marks۔ یہ pyramid ہے۔ X عین A کے اوپر ہے۔ ہمیں angle B X C چاہیے۔ یہ triangle B X C میں ہے، تو ہمیں اس کی تینوں sides چاہییں۔ Step دو: X A B میں A پر right angle ہے۔ X B squared ہے نو squared plus آٹھ squared، یعنی ایک سو پینتالیس۔ X C بھی یہی ہے، اور B C آٹھ ہے۔ یہ triangle B X C flat بنایا گیا ہے۔ یہ isosceles ہے، دو sides root ایک سو پینتالیس اور base آٹھ۔ Step چار: cosine rule۔ Cosine B X C ہے ایک سو پینتالیس، plus ایک سو پینتالیس، minus چونسٹھ، over دو ضرب ایک سو پینتالیس۔ Angle اڑتیس اعشاریہ آٹھ degrees ہے۔ ایک tempting طریقہ X B اور X C دونوں کے لیے نو لیتا ہے۔ لیکن نو صرف height X A ہے۔ اس سے باون اعشاریہ آٹھ degrees آتا، جو غلط ہے۔ تو angle B X C اڑتیس اعشاریہ آٹھ degrees ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی بغیر check کیے right angle فرض کرنا ہے۔ یہاں ایک سو پینتالیس plus ایک سو پینتالیس دو سو نوے ہے، چونسٹھ نہیں۔ تو یہ نوے degrees نہیں ہے۔
