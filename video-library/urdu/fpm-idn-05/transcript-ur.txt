Idea۔ Map پر ایک سیدھی سڑک کا سوچیں۔ آپ کو صرف دو جگہیں چاہئیں، پھر ruler۔ y equals دو x plus پانچ جیسا equation x اور y کو جوڑتا ہے۔ ہر جوڑی جو فٹ ہو ایک point ہے، اور points مل کر سیدھی line بناتے ہیں۔ سب سے آسان points وہ ہیں جہاں line axes کو cross کرتی ہے۔ y axis پر x صفر ہے۔ x axis پر y صفر ہے۔ تو y crossing کے لیے x equals صفر رکھیں، اور x crossing کے لیے y equals صفر۔ y equals کوئی number، ایک flat، horizontal line ہے۔ x equals کوئی number، ایک کھڑی، vertical line ہے۔ Origin سے گزرتی line کو ایک اور point چاہیے، کیونکہ دونوں crossings origin ہی ہیں۔ Exam میں لکھا ہوتا ہے: draw the line with equation۔ ہر line کے دو points نکالیں اور اسے پورے grid میں rule کریں۔

Method۔ پہلا step: x equals صفر رکھ کر y solve کریں، پھر y equals صفر رکھ کر x solve کریں۔ دوسرا step: اگر دونوں origin ہوں، یا ایک grid سے باہر ہو، تو کوئی اور x چنیں۔ تیسرا step: axes کے scale کے مطابق points plot کریں۔ چوتھا step: انہیں ruler سے join کریں اور پورے grid میں extend کریں۔ ہر line کو اس کے equation سے label کریں۔ پانچواں step: ایک اضافی point check کریں۔ Trap sign slip ہے، تو minus signs میں احتیاط کریں۔
