Idea۔ بارہ pounds کا bill x دوستوں میں بانٹیں۔ ہر ایک بارہ over x دیتا ہے۔ آپ صفر دوستوں میں نہیں بانٹ سکتے۔ ہزار دوستوں میں ہر ایک تقریباً کچھ نہیں دیتا، مگر پورا صفر کبھی نہیں۔ ان دو lines کو asymptotes کہتے ہیں۔ Rational curve ایک fraction ہے جس کے اوپر اور نیچے x ہو، جیسے a x plus b over c x plus d۔ اس کا vertical asymptote، y axis کے parallel ہوتا ہے۔ صفر سے divide نہیں کر سکتے، اس لیے وہاں denominator صفر نہیں ہوتا۔ Horizontal asymptote، جو x axis کے parallel ہے، وہ جگہ ہے جہاں x بہت بڑا ہو تو y ٹھہر جاتا ہے۔ تب سادہ numbers کی اہمیت نہیں رہتی۔ y equals دو x plus ایک، over x plus ایک لیں۔ جیسے x بڑھتا ہے، y دو کے قریب ہوتا جاتا ہے، یعنی دو over ایک۔ سوال کہتا ہے: write down an equation of the asymptote parallel to an axis۔ پورا equation لکھیں، x equals کچھ یا y equals کچھ۔

Method۔ پہلا step: vertical asymptote کے لیے denominator کو صفر کے برابر رکھ کر solve کریں۔ یہ اس value سے match کرنا چاہیے جو سوال کہتا ہے کہ x نہیں ہو سکتا۔ دوسرا step: horizontal asymptote کے لیے اوپر کے x کے coefficient کو نیچے کے x کے coefficient سے divide کریں۔ Signs دیکھیں۔ سات minus x کا coefficient minus ایک ہے۔ تیسرا اور چوتھا step: ہر جواب equation کی شکل میں لکھیں، اور vertical والے کو سوال سے check کریں۔ Trap صرف number لکھنا ہے۔ تین over دو asymptote نہیں ہے۔ x equals تین over دو asymptote ہے۔

Worked Example۔ جون دو ہزار بائیس۔ A curve C is y equals سات x minus دو، over، دو x minus تین، where x is not تین over دو۔ Write down the asymptote parallel to the y axis and the one parallel to the x axis۔ دو marks۔ پہلا step: y axis کے parallel۔ Denominator کو صفر کے برابر رکھیں۔ دو x minus تین صفر ہے، تو x تین over دو ہے۔ یہ سوال سے match کرتا ہے۔ دوسرا step: x axis کے parallel۔ اوپر x کا coefficient سات ہے۔ نیچے دو ہے۔ تو y سات over دو ہے۔ x کی بڑی values سے check کریں۔ دس پر y چار ہے۔ سو پر تین اعشاریہ پانچ چار۔ ہزار پر تین اعشاریہ پانچ۔ یہ سات over دو کے قریب ٹھہرتا ہے۔ غلط راستہ یہ ہے کہ constants کو divide کیا جائے: minus دو over minus تین۔ یہ دو over تین ہے، جہاں curve y axis کو cross کرتی ہے، یہ asymptote نہیں ہے۔ یہ curve ہے۔ ہر branch دونوں dashed lines کے قریب رہتی ہے مگر انہیں کبھی چھوتی نہیں۔ تو y axis کے parallel asymptote x equals تین over دو ہے۔ x axis کے parallel asymptote y equals سات over دو ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ عام غلطی sign slip ہے۔ اگر x plus چار صفر ہو تو x منفی چار ہے، چار نہیں۔ Number کو دوسری طرف لے جائیں تو اس کا sign بدل جاتا ہے۔
