Idea۔ Half pipe U شکل کا ہوتا ہے۔ Skater دونوں کناروں کے درمیان نیچے ہوتا ہے، اور ان کے باہر اوپر۔ Quadratic graph بھی ایسا ہی ہے: دونوں crossing points کے درمیان axis سے نیچے، اور ان کے باہر axis سے اوپر۔ Quadratic inequality میں x squared ہوتا ہے، جیسے تین x squared minus آٹھ x minus تین is less than صفر۔ Critical values وہ x values ہیں جہاں یہ صفر کے برابر ہو۔ یہ boundaries ہیں۔ ہمیں کون سا region چاہیے؟ U shape کے لیے less than صفر کا مطلب دونوں roots کے درمیان ہے۔ Greater than صفر کا مطلب ان کے باہر ہے، جسے دو الگ inequalities کی شکل میں لکھتے ہیں۔ اس question type میں پوچھا جاتا ہے: find the set of values of x۔ اندر کے لیے ایک interval دیں، یا باہر کے لیے دو inequalities۔

Method۔ پہلا step: ہر term ایک side پر لے جائیں تاکہ دوسری side صفر ہو۔ ممکن ہو تو x squared کو positive رکھیں۔ احتیاط سے collect کریں۔ غلطیاں یہیں ہوتی ہیں۔ دوسرا step: equals صفر والا version solve کریں، factorising یا formula سے۔ یہ critical values ہیں۔ تیسرا step: ان سے گزرتا parabola sketch کریں۔ Sketch region دکھاتا ہے۔ چوتھا اور پانچواں step: less than صفر کے لیے اندر کا حصہ، یا greater than صفر کے لیے باہر کے دو حصے چنیں۔ Trap باہر کے حصوں کو ایک inequality میں جوڑنا ہے۔

Worked Example۔ جنوری دو ہزار تئیس۔ Find the set of values of x for which تین x squared، minus آٹھ x، minus تین، is less than صفر۔ چار marks۔ پہلا step: ایک side پہلے ہی صفر ہے، اور x squared کا coefficient، تین، positive ہے۔ تو graph U شکل کا ہے۔ دوسرا step: تین x squared minus آٹھ x minus تین equals صفر solve کریں۔ یہ factorise ہوتا ہے تین x plus ایک، ضرب x minus تین۔ تو x منفی ایک over تین، یا تین ہے۔ یہ critical values ہیں۔ تیسرا step: منفی ایک over تین اور تین سے گزرتا U sketch کریں۔ ہمیں expression less than صفر چاہیے۔ وہ وہاں ہے جہاں curve axis سے نیچے ہے، یہاں shade کیا گیا ہے۔ چوتھا step: region چنیں۔ Curve roots کے درمیان axis سے نیچے ہے۔ تو جواب ہے x منفی ایک over تین اور تین کے درمیان۔ ایک آسان لگنے والا غلط راستہ باہر کا region ہے، x less than منفی ایک over تین، یا x greater than تین۔ یہ greater than صفر کا جواب ہے۔ ہمیں less than چاہیے۔ Check کریں۔ x equals صفر پر value منفی تین ہے، صفر سے کم، اور صفر roots کے درمیان ہے۔ x equals چار پر value تیرہ ہے، تو یہ fail ہوتا ہے۔ تو values کا set ہے x منفی ایک over تین اور تین کے درمیان۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ عام غلطی باہر کے regions کو ایک inequality میں جوڑنا ہے۔ تین is less than x is less than minus ایک over دو ناممکن ہے۔ or کے ساتھ دو inequalities لکھیں۔

Answer۔ بارہ کو دوسری طرف لے جائیں: دس x squared plus سات x minus بارہ is less than صفر۔ یہ factorise ہوتا ہے دو x plus تین، ضرب پانچ x minus چار۔ Critical values منفی تین over دو اور چار over پانچ ہیں۔ Coefficient positive ہے، تو graph U ہے۔ Less than صفر کا مطلب axis سے نیچے، roots کے درمیان: x منفی تین over دو اور چار over پانچ کے درمیان۔ عام غلط جواب بارہ کو دوسری طرف لے جائے بغیر factorise کرتا ہے، اور x less than بارہ دیتا ہے۔ یہ غلط ہے۔ پہلے ایک side صفر ہونی چاہیے۔ یاد رکھیں: ایک side صفر، critical values نکالیں، U sketch کریں، region چنیں، اور set لکھیں۔
