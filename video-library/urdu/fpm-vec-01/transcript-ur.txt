Idea۔ سکول پیدل جانے کا سوچیں: چار blocks مشرق اور تین blocks شمال۔ یہ journey ایک vector ہے۔ اس کی size بھی ہے اور direction بھی۔ ہم اسے i اور j سے لکھتے ہیں۔ i ایک unit across ہے، اور j ایک unit up۔ Position vector بتاتا ہے کہ point کہاں ہے، fixed point O سے ناپ کر، جسے origin کہتے ہیں۔ A کا position vector، O سے A تک کی journey ہے۔ اسے vector O A لکھتے ہیں۔ A سے B تک کا vector، A سے B کی journey ہے۔ آپ A سے واپس O جا سکتے ہیں، پھر O سے B۔ واپس جانا minus vector O A ہے۔ اس لیے vector A B برابر vector O B minus vector O A۔ اس question type میں دو position vectors دیے جاتے ہیں اور points کے درمیان journey پوچھی جاتی ہے۔ کبھی ایک point اور journey دی جاتی ہے، اور دوسرے point کا position vector پوچھا جاتا ہے۔

Method۔ Step ایک: مطلوبہ vector کو end minus start لکھیں۔ Step دو: ہر position vector کو brackets میں رکھ کر substitute کریں۔ Brackets اہم ہیں، کیونکہ minus ہر حصے پر لگنا چاہیے۔ Step تین: i parts subtract کریں، پھر j parts۔ Step چار: position vector چاہیے تو journey کو start میں add کریں: vector O B برابر vector O A plus vector A B۔ Trap یہ ہے کہ الٹا subtract کر دیا جائے۔ Start minus end سے journey الٹی ملتی ہے، جو answer کا negative ہے۔

Worked Example۔ جون دو ہزار انیس۔ Origin O سے، point A کا position vector چار i plus تین j ہے، اور point B کا i plus سات j۔ vector A B کو i اور j میں نکالیں۔ دو marks۔ یہ picture ہے۔ A چار across اور تین up ہے۔ B ایک across اور سات up ہے۔ ہمیں A سے B تک کا arrow چاہیے۔ End minus start۔ vector A B برابر vector O B minus vector O A۔ اب brackets کے ساتھ substitute کریں: i plus سات j، minus، چار i plus تین j۔ i parts subtract کریں: ایک minus چار برابر minus تین۔ j parts subtract کریں: سات minus تین برابر چار۔ ایک tempting غلط طریقہ start minus end ہے: چار i plus تین j، minus، i plus سات j۔ اس سے تین i minus چار j ملتا ہے، جو B سے واپس A کی journey ہے۔ تو vector A B برابر minus تین i plus چار j۔ Picture سے check کریں: A سے تین left اور چار up جائیں تو B آ جاتا ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک common mistake brackets چھوڑ دینا ہے۔ پھر دوسرے vector کا صرف پہلا حصہ subtract ہوتا ہے۔ Plus تین j کو minus تین j بننا چاہیے تھا۔

Your Turn۔ اب آپ کی باری، جون دو ہزار بائیس سے۔ A کا position vector تین i minus دو j ہے۔ vector A B چھ i plus آٹھ j ہے۔ B کا position vector نکالیں۔ اپنا جواب لکھیں، پھر Continue to Answer کا بٹن دبائیں۔

Answer۔ ہمیں B کا position vector چاہیے، یعنی vector O B۔ پہلے A تک جائیں، پھر A B کے ساتھ۔ اس لیے vector O B برابر vector O A plus vector A B۔ i parts add کریں: تین plus چھ برابر نو۔ j parts add کریں: minus دو plus آٹھ برابر چھ۔ تو B کا position vector نو i plus چھ j ہے۔ سب سے common غلط answer اس کے بجائے subtract کرتا ہے: minus تین i minus دس j۔ یہ end minus start rule وہاں لگاتا ہے جہاں سوال start اور journey دیتا ہے، اس لیے ایک مختلف point ملتا ہے۔ یاد رکھیں: دو positions ہوں تو subtract، end minus start۔ Start اور journey ہو تو add۔
