Idea۔ Theme park میں آپ کا قد ایک metre سے زیادہ اور دو metres سے کم ہونا چاہیے۔ صرف وہ لوگ سواری کرتے ہیں جو ہر rule پاس کریں۔ Graph پر inequality، x اور y کے بارے میں ایک rule ہے۔ Region وہ تمام points ہیں جو سب rules پاس کریں۔ ایک inequality grid کو دو حصوں میں بانٹتی ہے۔ اس کی line boundary ہے۔ ایک طرف کے points inequality کو true بناتے ہیں۔ دوسری طرف کے false۔ True side معلوم کرنے کے لیے test point استعمال کریں۔ ایسا point چنیں جو line پر نہ ہو، جیسے origin۔ اسے inequality میں رکھیں۔ اگر true ہو تو وہی side shade کریں جس میں وہ point ہے۔ سوال کہتا ہے: show, by shading, the region R۔ آپ وہ ایک region shade کرتے ہیں جہاں ہر inequality true ہو، اور اس میں R لکھتے ہیں۔

Method۔ پہلا step: ہر inequality کے لیے باری باری ایسا test point چنیں جو اس کی line پر نہ ہو۔ Origin سب سے بہتر ہے۔ دوسرا step: بتائیں کہ test point true ہے یا نہیں، اور مطلوبہ side mark کریں۔ تیسرا step: grid کا وہ حصہ تلاش کریں جو ہر line کی مطلوبہ side پر ہو۔ یہ عموماً triangle ہوتا ہے۔ چوتھا step: اسے shade کریں اور R label کریں۔ Trap line پر موجود point کو test کرنا ہے۔ وہ less than or equal sign کے ساتھ ہمیشہ فٹ ہوتا ہے، اس لیے کچھ نہیں بتاتا۔
