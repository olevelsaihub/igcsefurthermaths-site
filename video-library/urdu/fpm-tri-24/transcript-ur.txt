Idea۔ ایک wheel کو دگنی رفتار سے گھمائیں تو وہ top پر دگنی بار پہنچتا ہے۔ اس لیے sine دو x، sine x سے دگنی تیزی سے repeat ہوتا ہے، اور وہی height زیادہ بار چھوتا ہے۔ یعنی extra solutions۔ بریکٹ کے اندر کا angle، جیسے دو x minus پچھتر، compound angle ہے۔ اسے u کہتے ہیں۔ x جب صفر سے ایک سو اسّی تک چلتا ہے تو u ایک مختلف interval میں چلتا ہے۔ Inverse sine ایک ہی answer دیتا ہے، یعنی principal value۔ باقی answers graph کی symmetry سے ملتے ہیں۔ sine کا دوسرا answer، ایک سو اسّی minus پہلا answer ہے۔ پھر پورے turns add یا subtract کریں۔ اس type میں دی گئی interval میں x کے لیے solve کرنا ہوتا ہے۔ پہلے u نکالیں، جو values interval میں ہوں وہ رکھیں، پھر x میں واپس بدلیں۔

Method۔ Step ایک: rearrange کریں تاکہ compound angle کی ایک trig ratio، ایک number کے برابر ہو۔ Step دو: اس angle کو u لیں، اور x کی interval کو u کی interval میں بدلیں۔ Step تین: principal value نکالیں، پھر نئی interval میں باقی تمام u۔ Step چار: bracket کو undo کر کے x نکالیں، اور چیک کریں کہ ہر x اصل interval میں ہے۔ Trap یہ ہے کہ u کے لیے پرانی interval استعمال ہو جائے۔ پھر بہت بڑی values رہ جاتی ہیں اور negative values چھوٹ جاتی ہیں۔

Worked Example۔ جنوری دو ہزار بیس۔ x کے لیے solve کریں، صفر سے ایک سو اسّی تک، ایک سو اسّی شامل نہیں، nearest integer تک: sine of دو x minus پچھتر degrees برابر minus صفر اعشاریہ پانچ ایک پانچ۔ تین marks۔ u کو دو x minus پچھتر لیں۔ x کی interval کو دگنا کریں، پھر پچھتر minus کریں۔ تو u، minus پچھتر سے دو سو پچاسی تک چلتا ہے۔ Inverse sine سے u برابر minus تیس اعشاریہ نو نو سات ملتا ہے۔ یہ interval کے اندر ہے، اس لیے رکھیں۔ Symmetry سے دوسری value، ایک سو اسّی minus اس کے برابر ہے: دو سو دس اعشاریہ نو نو سات۔ تین سو ساٹھ add کریں تو تین سو انتیس ملتا ہے۔ یہ بہت بڑا ہے، اس لیے reject کریں۔ اب undo کریں: پچھتر add کریں، پھر دو سے divide کریں۔ x برابر بائیس، اور x برابر ایک سو تینتالیس ملتا ہے۔ ایک tempting غلط طریقہ یہ ہے کہ u کو صفر سے تین سو ساٹھ میں ڈھونڈا جائے۔ اس سے x برابر ایک سو تینتالیس اور دو سو دو ملتا ہے۔ دوسرا range سے باہر ہے، اور بائیس چھوٹ جاتا ہے۔ تو x برابر بائیس یا ایک سو تینتالیس۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔
