Idea۔ ایک پہاڑی سوچیں۔ نقشہ ہر point پر اس کی steepness بتاتا ہے، مگر اونچائی نہیں بتاتا۔ کیا ہم steepness سے پہاڑی دوبارہ بنا سکتے ہیں؟ جی ہاں، اور یہ question type یہی کرتی ہے۔ Gradient function، f dash of x یا d y by d x ہے۔ اس سے واپس جانا integration کہلاتا ہے۔ ہر power میں ایک بڑھائیں اور نئی power سے divide کریں۔ یہ c کیوں؟ differentiate کرنے سے کوئی بھی constant ختم ہو جاتا ہے۔ تو x squared، x squared plus دو، اور x squared minus دو، سب کا gradient ایک ہی ہے۔ Integrate کرتے وقت constant c رکھنا ضروری ہے۔ Curve پر ایک point صحیح والا چنتا ہے۔ اس کے x اور y کو equation میں رکھیں اور c کے لیے solve کریں۔ ان سوالوں میں gradient function اور ایک point دیا ہوتا ہے، اور equation پوچھی جاتی ہے، یا کچھ show کرنا ہوتا ہے، جیسے کہ curve origin سے گزرتی ہے۔

Method۔ Step ایک: ہر term کو integrate کریں۔ power میں ایک بڑھائیں اور نئی power سے divide کریں۔ Step دو: c add کریں، کیونکہ differentiate کرنے سے کوئی بھی constant ختم ہو جاتا ہے۔ Step تین: معلوم point substitute کریں۔ Step چار: c کے لیے solve کریں، پھر curve لکھیں۔ دو unknowns کے لیے دو points چاہییں۔ Trap یہ ہے کہ c چھوڑ دیا جائے، یا اسے صفر فرض کر لیا جائے۔ پہلے c add کریں، پھر point سے اسے نکالیں۔

Common Mistake۔ ایک عام غلطی یہ ہے: نئی power سے divide کرنے کی جگہ multiply کر دیا جائے۔ بارہ x squared سے بارہ x cubed over تین ملتا ہے، جو چار x cubed ہے۔
