Idea۔ ایک سیدھا راستہ ٹیڑھے دریا سے ملتا ہے۔ آگے جا کر وہ دریا کو دوبارہ cross کر سکتا ہے۔ یہاں ایک line، curve سے ایک ایسے point پر ملتی ہے جو آپ کو معلوم ہے۔ آپ کو وہ دوسری جگہ نکالنی ہے جہاں وہ ملتے ہیں۔ Curve ایک fraction ہے جس کے denominator میں x ہے۔ جہاں line اور curve ملتے ہیں، y values برابر ہوتی ہیں۔ تو line کو curve کے برابر لکھیں۔ Fraction ختم کرنے کے لیے ہر term کو denominator سے multiply کریں، یہاں x minus ایک۔ Every term کا مطلب دونوں sides۔ آپ کو quadratic ملتا ہے۔ Known point ایک root ہے۔ دوسرا root D ہے۔ سوال کہتا ہے: find the x coordinate of D۔

Method۔ پہلا step: line کو curve کے برابر لکھیں۔ دوسرا step: ہر term کو denominator سے multiply کریں۔ تیسرا step: expand کریں اور صفر تک rearrange کریں۔ چوتھا step: factorise کریں۔ Known x value ایک root ہے۔ پانچواں step: known point کو reject کریں، اور دوسرا root دیں۔ Trap known point کو جواب دینا ہے۔

Worked Example۔ جنوری دو ہزار بیس۔ The curve C is y equals q x minus دو، over x minus p۔ It crosses the y axis at A۔ The line l، y equals x plus دو، is the normal at A۔ Normal وہ line ہے جو curve سے right angles پر ہو۔ From part a، p is ایک and q is تین۔ The line meets C again at D۔ Find the x coordinate of D۔ چار marks۔ یہ تصویر ہے۔ Asymptote وہ line ہے جس کے قریب curve آتی ہے مگر کبھی پہنچتی نہیں۔ Line A سے گزرتی ہے اور curve کو D پر دوبارہ ملتی ہے۔ پہلا step: line کو curve کے برابر لکھیں، پھر ہر term کو x minus ایک سے multiply کریں۔ x plus دو، ضرب x minus ایک، equals تین x minus دو۔ دوسرا step: expand کر کے rearrange کریں۔ x squared minus دو x equals صفر۔ Factorise کریں: x ضرب x minus دو equals صفر۔ تو x صفر ہے یا دو۔ صفر known point A ہے۔ تو D کا x دو ہے۔ غلط راستہ x equals صفر ہے۔ مگر یہ A ہے، جہاں سے ہم نے شروع کیا تھا۔ تو D کا x coordinate دو ہے۔ Check: x equals دو پر curve چار over ایک، یعنی چار دیتی ہے، اور line دو plus دو، یعنی چار۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ عام غلطی left side کو ویسا ہی چھوڑ دینا ہے۔ اس سے x plus دو equals تین x minus دو آتا ہے۔ اس سے quadratic ختم ہو جاتا ہے، اور marks بھی۔

Your Turn۔ اب آپ کوشش کریں، جون دو ہزار بائیس سے۔ The curve is پانچ x plus ایک، over تین x minus چھ۔ The normal at A meets the curve again at D۔ Give the x coordinate of D as an improper fraction، یعنی ایسا fraction جس کا top bottom سے بڑا ہو۔ اپنا جواب لکھیں، پھر Continue to Answer کا بٹن دبائیں۔

Answer۔ Line میں y کو subject بنائیں: بہتر x minus گیارہ، over چھیاسٹھ۔ اسے curve کے برابر لکھیں۔ Cross multiply کریں۔ چھیاسٹھ times پانچ x plus ایک، equals بہتر x minus گیارہ، ضرب تین x minus چھ۔ دونوں sides expand کریں۔ Rearrange کریں: دو سو سولہ x squared minus سات سو پچانوے x equals صفر۔ Factorise کریں۔ x equals صفر A ہے، تو اسے reject کریں۔ x سات سو پچانوے over دو سو سولہ ہے، جو دو سو پینسٹھ over بہتر ہے۔ عام غلط جواب x equals صفر ہے، یعنی known point A۔ ایک اور غلط جواب decimal دیتا ہے، تین اعشاریہ چھ آٹھ۔ یہ improper fraction نہیں، اس لیے آخری mark جاتا ہے۔ یاد رکھیں: line equals curve، ہر term کو multiply کریں، صفر تک rearrange کریں، factorise کریں، known point reject کریں۔
