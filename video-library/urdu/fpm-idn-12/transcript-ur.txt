Idea۔ کوئی real number squared کرنے پر negative نہیں ہوتا۔ تین squared نو ہے، اور منفی تین، all squared، بھی نو ہے۔ تو کوئی real number منفی انیس نہیں بنا سکتا۔ Root، x کی وہ value ہے جو expression کو صفر بنائے۔ Real root وہ root ہے جو real number ہو۔ Discriminant بتاتا ہے کہ quadratic کے کتنے real roots ہیں۔ a x squared plus b x plus c کے لیے یہ b squared minus چار a c ہے۔ Positive کا مطلب دو roots، صفر کا مطلب ایک، negative کا مطلب کوئی نہیں۔ اب cubic۔ اگر وہ x minus k ضرب quadratic ہے، اور quadratic کے کوئی real roots نہیں، تو واحد real root k ہے۔ Curve x axis کو ایک بار cross کرتی ہے۔ سوال کہتا ہے: hence show that there is only one real root۔ Hence کا مطلب ہے پچھلے part کا result استعمال کریں۔ Show that کا مطلب ہے result دیا ہوا ہے، اور آپ کی working کو اسے prove کرنا ہے۔ Divide کریں، discriminant نکالیں، بتائیں اس کا مطلب کیا ہے، اور root کا نام لیں۔

Method۔ پہلا step: known factor سے divide کر کے quadratic نکالیں۔ دوسرا step: b squared minus چار a c نکالیں، numbers دکھاتے ہوئے۔ تیسرا step: لکھیں کہ یہ negative ہے، تو کوئی real roots نہیں۔ چوتھا step: واحد real root linear factor سے آتا ہے۔ اس کا نام لیں۔ Trap negative number لکھ کر رک جانا ہے۔ ہمیشہ لکھیں کہ اس کا مطلب کیا ہے۔
