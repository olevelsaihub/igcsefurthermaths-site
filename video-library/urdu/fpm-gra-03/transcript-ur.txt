Idea۔ Sketch ایک تیز freehand drawing ہے، جیسے rough map جو دکھاتا ہے کہ سڑکیں مرکزی گلیوں کو کہاں cross کرتی ہیں۔ یہ curve کی shape دکھاتا ہے اور key points label کرتا ہے۔ اس کا scale کے مطابق ہونا ضروری نہیں۔ Curve y axis کو وہاں cross کرتی ہے جہاں x صفر ہو۔ x axis کو وہاں cross کرتی ہے جہاں y صفر ہو۔ ہر crossing کو coordinates کی شکل میں لکھیں۔ Log اور exponential curves کا asymptote ہوتا ہے۔ یہ وہ line ہے جس کے curve قریب سے قریب تر ہوتی جاتی ہے مگر اسے کبھی چھوتی نہیں۔ Curve y برابر L N x، یعنی x کا natural log، ایک، صفر سے گزرتی ہے، اور asymptote x برابر صفر ہے۔ اس سوال میں لکھا ہوتا ہے: sketch the curve and label the key points۔ پہلے algebra کریں، پھر draw کریں۔

Method۔ پہلا step: y intercept کے لیے x برابر صفر رکھیں۔ دوسرا step: x intercepts کے لیے y برابر صفر رکھیں۔ اگر log صفر کے برابر ہو تو اس کا bracket ایک کے برابر ہوتا ہے۔ تیسرا step: asymptote یا turning point نکالیں۔ Log of x plus k کا asymptote x برابر minus k ہے۔ Exponential، a to the power x plus k، کا asymptote y برابر k ہے۔ Parabola کا turning point completing the square سے ملتا ہے۔ چوتھا step: shape بنائیں اور label کریں۔ Trap وہ curve ہے جو اپنے asymptote کو چھو لے۔ اسے قریب آنا ہے، مگر اپنی طرف رہنا ہے۔

Worked Example۔ جون دو ہزار چوبیس۔ C ہے y برابر minus log base چار of، x plus چار۔ C کا sketch بنائیں۔ Label کریں کہ یہ axes کو کہاں ملتی ہے، اور کوئی بھی asymptote۔ چار marks۔ پہلا step: asymptote۔ Log کے لیے bracket کا positive ہونا ضروری ہے، تو x plus چار، صفر سے بڑا ہے۔ Curve x برابر minus چار کے دائیں طرف رہتی ہے۔ وہی line asymptote ہے۔ دوسرا step: x برابر صفر رکھیں۔ Log base چار of چار ایک ہے، تو y minus ایک ہے۔ تیسرا step: y برابر صفر رکھیں۔ پھر x plus چار ایک ہے، تو x minus تین ہے۔ ایک tempting غلط راستہ یہ ہے کہ x intercept کے لیے x plus چار کو صفر کے برابر رکھا جائے۔ اس سے minus چار آتا ہے، جو asymptote ہے۔ چوتھا step: shape۔ سادہ log curve اوپر جاتی ہے۔ Minus sign اسے الٹ دیتا ہے، تو یہ نیچے جاتی ہے۔ یہ asymptote کے ساتھ نیچے آتی ہے، دونوں points سے گزرتی ہے، اور آہستہ آہستہ گرتی رہتی ہے۔ تو sketch میں ایک گرتی ہوئی curve ہے جو دونوں points سے گزرتی ہے، اور asymptote x برابر minus چار ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک عام غلطی crossing کو ایک number سے label کرنا ہے، جیسے minus تین۔ سوال coordinates مانگتا ہے۔ Asymptote کو equation کی شکل میں لکھیں، صرف number نہیں۔

Your Turn۔ اب آپ کوشش کریں، جون دو ہزار بائیس سے۔ C ہے y برابر log base دس of، x plus دو۔ C کا sketch بنائیں اور label کریں کہ یہ axes کو کہاں ملتی ہے۔ اپنا جواب لکھیں، پھر Continue to Answer کا بٹن دبائیں۔

Answer۔ x برابر صفر رکھیں: y ہے log base دس of دو، یعنی صفر اعشاریہ تین صفر ایک۔ y برابر صفر رکھیں: x plus دو ایک ہے، تو x minus ایک ہے۔ اسے draw کریں۔ Asymptote x برابر minus دو ہے۔ Curve اس line کے ساتھ بہت نیچے سے آہستہ آہستہ اوپر جاتی ہے، دونوں points سے گزرتی ہے۔ سب سے عام غلط جواب x plus دو کو صفر کے برابر رکھنا ہے، جس سے minus دو آتا ہے۔ وہ asymptote ہے، intercept نہیں۔ یاد رکھیں: y کے لیے x برابر صفر، x کے لیے y برابر صفر، asymptote نکالیں، پھر draw اور label کریں۔
