Idea۔ دو سیدھی سڑکیں ایک junction پر ملتی ہیں۔ Junction کے ساتھ چار corners ہوتے ہیں۔ Rational curve کے دو الگ حصے ہوتے ہیں، جنہیں branches کہتے ہیں، اور یہ دو opposite corners میں ہوتے ہیں۔ Curve y equals ایک over x سب سے سادہ مثال ہے۔ Asymptotes کو dashed lines سے بنایا جاتا ہے۔ ہر ایک کو اس کے equation سے label کریں۔ Vertical line کا equation x equals کچھ ہوتا ہے۔ Horizontal line کا y equals کچھ۔ Axis crossings ایک branch پر ہوتی ہیں۔ تو وہ بتاتی ہیں کہ وہ branch کس corner میں ہے۔ دوسری branch opposite corner میں ہے۔ اگر شک ہو تو ایک اور point test کریں۔ اس سوال میں لکھا ہوتا ہے: sketch the curve, showing the asymptotes and where it crosses the axes۔ آپ دونوں branches، دونوں dashed lines، اور label کیے ہوئے points دکھاتے ہیں۔

Method۔ پہلا step: دونوں asymptotes کو dashed lines سے بنائیں اور label کریں۔ دوسرا step: axis crossings کو ان کے coordinates کے ساتھ mark کریں۔ تیسرا step: corners طے کریں۔ دیکھیں intercepts دونوں lines کے مقابلے میں کہاں ہیں۔ وہ branch وہیں جاتی ہے۔ Opposite corner confirm کرنے کے لیے دوسری طرف ایک point test کریں۔ چوتھا step: ہر branch کو smoothly بنائیں۔ یہ دونوں lines کے قریب سے قریب تر ہوتی جاتی ہے، مگر انہیں نہ چھوتی ہے نہ cross کرتی ہے۔ Trap صرف ایک branch بنانا ہے۔

Worked Example۔ جنوری دو ہزار بائیس۔ The curve C has equation y equals دو x minus ایک، over، x plus چار۔ Sketch C۔ Show the asymptotes and where it crosses the axes۔ تین marks۔ پہلا step: asymptotes۔ Bottom، x plus چار، x equals منفی چار پر صفر ہے۔ x کے coefficients دو اور ایک ہیں، تو y equals دو۔ دونوں کو dashed lines سے بنائیں۔ دوسرا step: crossings۔ x equals صفر رکھیں: y منفی ایک over چار ہے۔ Top کو صفر کے برابر رکھیں: x ایک over دو ہے۔ دونوں points mark کریں۔ تیسرا step: corners۔ دونوں points x equals منفی چار کے دائیں اور y equals دو کے نیچے ہیں۔ تو ایک branch bottom right ہے۔ x equals منفی پانچ test کریں: y گیارہ ہے۔ یہ بائیں اور اوپر ہے، تو دوسری branch top left ہے۔ چوتھا step: دونوں branches smoothly بنائیں۔ ہر ایک dashed lines کے قریب رہتی ہے مگر انہیں چھوتی نہیں۔ غلط راستہ یہ ہے کہ branch asymptote کو cross کر جائے، یا اس سے دور مڑ جائے۔ Branch کو قریب آتے رہنا ہے، اور اپنی طرف رہنا ہے۔ تو sketch میں دو branches ہیں، dashed lines x equals منفی چار اور y equals دو ہیں، اور points صفر، منفی ایک over چار اور ایک over دو، صفر ہیں۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ عام غلطی صرف وہ branch بنانا ہے جو intercepts سے گزرتی ہے۔ Rational curve کی دو branches ہوتی ہیں۔ دوسری دونوں dashed lines کے opposite corner میں ہوتی ہے۔

Answer۔ Vertical asymptote x equals منفی ایک ہے۔ Horizontal asymptote y equals تین over ایک ہے، یعنی تین۔ x equals صفر رکھیں: y منفی دو ہے۔ Top کو صفر کے برابر رکھیں: x دو over تین ہے۔ دونوں points x equals منفی ایک کے دائیں اور y equals تین کے نیچے ہیں۔ تو ایک branch bottom right ہے۔ x equals منفی دو test کریں: y آٹھ ہے۔ تو دوسری branch top left ہے۔ دونوں بنائیں، dashed lines کے قریب رہتے ہوئے۔ سب سے عام غلط جواب صرف ایک branch بنانا ہے، یا curve کو dashed line سے cross کرا دینا۔ دو branches، ہر ایک اپنی طرف، shape کا mark دلاتی ہیں۔ یاد رکھیں: dashed asymptotes، intercepts، corners چنیں، دو smooth branches بنائیں۔
