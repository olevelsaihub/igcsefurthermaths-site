Method۔ پہلا step: y axis کے لیے x equals صفر substitute کر کے simplify کریں۔ دوسرا step: x axis کے لیے numerator کو صفر کے برابر رکھ کر solve کریں۔ نیچے والا حصہ کبھی استعمال نہ کریں۔ تیسرا step: ہر جواب exact fractions کے ساتھ coordinates کی شکل میں لکھیں۔ چوتھا step: واپس substitute کر کے check کریں۔ Trap صرف ایک coordinate ہے۔ منفی پانچ over تین point نہیں ہے۔ ایک اور trap: x axis کے لیے denominator کو صفر کے برابر رکھنا۔ اس سے asymptote آتا ہے، intercept نہیں۔

Worked Example۔ نومبر دو ہزار چوبیس۔ A curve has equation y equals پانچ x minus دو، over، تین x plus دو۔ Find the coordinates of the point where it meets the x axis, and the point where it meets the y axis۔ دو marks۔ پہلا step: y axis۔ x equals صفر رکھیں۔ Top منفی دو ہے۔ Bottom دو ہے۔ تو y منفی ایک ہے۔ Point ہے صفر، منفی ایک۔ دوسرا step: x axis۔ Top کو صفر کے برابر رکھیں۔ پانچ x minus دو صفر ہے، تو x دو over پانچ ہے۔ Point ہے دو over پانچ، صفر۔ Substitute کر کے check کریں۔ x equals دو over پانچ پر top صفر ہے۔ Bottom سولہ over پانچ ہے، جو صفر نہیں۔ تو y صفر ہے، جیسا چاہیے تھا۔ غلط راستہ یہ ہے کہ x axis کے لیے bottom کو صفر کے برابر رکھا جائے۔ تین x plus دو صفر سے منفی دو over تین آتا ہے۔ مگر یہ asymptote ہے، جہاں curve کبھی نہیں پہنچتی۔ یہ curve اپنے دو points کے ساتھ ہے۔ Dashed lines asymptotes ہیں۔ تو curve x axis کو دو over پانچ، صفر پر، اور y axis کو صفر، منفی ایک پر meet کرتی ہے۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ عام غلطی صرف ایک number دینا ہے۔ منفی ایک کافی نہیں۔ سوال coordinates مانگتا ہے، تو لکھیں صفر، منفی ایک۔
