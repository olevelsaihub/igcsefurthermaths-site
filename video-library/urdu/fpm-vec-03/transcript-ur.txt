Idea۔ Compass کی needle direction دکھاتی ہے، فاصلہ نہیں۔ unit vector ایسا ہی ہے۔ یہ بالکل ایک length کا vector ہے۔ یہ دیے گئے vector کی طرف ہی point کرتا ہے۔ Parallel کا مطلب ہے اسی طرف point کرنا، یا بالکل الٹی طرف۔ Vector کو length ایک تک کیسے چھوٹا کریں؟ اسے اس کی اپنی magnitude سے divide کریں۔ کسی number سے divide کرنے سے ہر part scale ہوتا ہے، اور direction وہی رہتی ہے۔ تین i plus چار j کی magnitude پانچ ہے۔ اکثر پہلے vector نکالنا پڑتا ہے۔ مثلاً vector Q S برابر vector P S minus vector P Q۔ End minus start۔ پھر اس vector کو اس کی magnitude سے divide کریں۔ اس question type میں دیے گئے vector کے parallel unit vector مانگا جاتا ہے۔ Vector نکالیں، اس کی length نکالیں، اور divide کریں۔

Method۔ Step ایک: مطلوبہ vector components میں نکالیں، ضرورت ہو تو position vectors subtract کریں۔ Step دو: Pythagoras سے اس کی magnitude نکالیں۔ Step تین: ہر component کو magnitude سے divide کریں۔ Step چار: simplify کریں، اور answer مانگی گئی form میں دیں۔ Trap یہ ہے کہ صرف ایک part کو divide کیا جائے، یا کسی اور vector کی length سے divide کیا جائے۔ دونوں parts، اور وہی vector۔

Worked Example۔ جنوری دو ہزار بائیس۔ vector P Q برابر دو i plus تین j ہے۔ vector P S برابر minus تین i plus پندرہ j ہے۔ vector Q S کے parallel unit vector نکالیں۔ چار marks۔ پہلے vector Q S۔ End minus start: vector P S minus vector P Q۔ Minus تین i plus پندرہ j، minus، دو i plus تین j۔ یہ minus پانچ i plus بارہ j ہے۔ اب magnitude۔ Minus پانچ squared برابر پچیس۔ بارہ squared برابر ایک سو چوالیس۔ Sum ایک سو انہتر ہے، اور اس کا square root تیرہ ہے۔ ہر component کو تیرہ سے divide کریں۔ Unit vector ہے minus پانچ over تیرہ i، plus بارہ over تیرہ j۔ Check کریں کہ length ایک ہے۔ پچیس over ایک سو انہتر، plus ایک سو چوالیس over ایک سو انہتر، برابر ایک سو انہتر over ایک سو انہتر، یعنی ایک۔ ایک tempting غلط طریقہ اس کے بجائے vector P S کی length سے divide کرتا ہے۔ وہ length root دو سو چونتیس ہے۔ Result کی length تقریباً صفر اعشاریہ آٹھ پانچ ہے، ایک نہیں۔ یہ unit vector نہیں ہے۔ تو Q S کے parallel unit vector ہے، ایک over تیرہ ضرب، minus پانچ i plus بارہ j۔ یہ وضاحت olevels dot com کی ہے، یہ official mark scheme نہیں ہے۔

Common Mistake۔ ایک common mistake صرف ایک component کو divide کرنا ہے۔ Minus پانچ over تیرہ i، plus بارہ j، کی length ایک نہیں ہوتی۔ دونوں parts کو تیرہ سے divide کریں۔
