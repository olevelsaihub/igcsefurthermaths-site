Idea. A sketch is a quick freehand drawing, like a rough map that shows where the roads cross the main streets. It shows the shape of the curve and labels the key points. It need not be to scale. A curve crosses the y axis where x is nought. It crosses the x axis where y is nought. Write each crossing as coordinates. Log and exponential curves have an asymptote. That is a line the curve gets closer and closer to, but never touches. The curve y equals L N x, the natural log of x, passes through one, nought, with the asymptote x equals nought. This question says: sketch the curve and label the key points. Do the algebra first, then draw.

Method. Step one: put x equals nought for the y intercept. Step two: put y equals nought for the x intercepts. If a log equals nought, its bracket equals one. Step three: find the asymptote or turning point. A log of x plus k has the asymptote x equals minus k. An exponential, a to the x plus k, has the asymptote y equals k. A parabola's turning point comes from completing the square. Step four: draw the shape and label it. The trap is a curve that touches its asymptote. It must get close, but stay on its own side.

Worked example. June twenty twenty four. C is y equals minus log base four of, x plus four. Sketch C. Label where it meets the axes, and any asymptote. Four marks. Step one: the asymptote. A log needs a positive bracket, so x plus four is more than nought. The curve stays right of x equals minus four. That line is the asymptote. Step two: put x equals nought. Log base four of four is one, so y is minus one. Step three: put y equals nought. Then x plus four is one, so x is minus three. A tempting wrong route is to set x plus four equal to nought for the x intercept. That gives minus four, which is the asymptote. Step four: the shape. A plain log curve rises. The minus sign flips it, so it falls. It comes down beside the asymptote, through both points, and keeps falling slowly. So the sketch shows a falling curve through both points, with the asymptote x equals minus four. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is labelling a crossing with one number, like minus three. The question asks for coordinates. Write the asymptote as an equation, not a bare number.

Your turn. Now you try, from June twenty twenty two. C is y equals log base ten of, x plus two. Sketch C and label where it meets the axes. Write your answer, then choose Continue to Answer.

Answer. Put x equals nought: y is log base ten of two, which is nought point three zero one. Put y equals nought: x plus two is one, so x is minus one. Draw it. The asymptote is x equals minus two. The curve rises slowly from far down beside that line, through both points. The most common wrong answer sets x plus two equal to nought, and gives minus two. That is the asymptote, not an intercept. Remember: x equals nought for y, y equals nought for x, find the asymptote, then draw and label.
