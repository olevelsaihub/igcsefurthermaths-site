Where a rational curve crosses the axes

Idea. Every point on the y axis has x equal to nought. Every point on the x axis has y equal to nought. So ask which coordinate is nought. Here a curve crosses both. A fraction is zero only when its top, the numerator, is zero. Nought over five is nought. But five over nought does not exist. So for the x axis, set only the top equal to nought. For the y axis, put x equals nought. For y equals a x plus b over c x plus d, that gives b over d. The point is nought, b over d. This question says: find where the curve crosses the x axis and the y axis. Answer with coordinates, using exact fractions.

Method. Step one: for the y axis, substitute x equals nought and simplify. Step two: for the x axis, set the numerator to nought and solve. Never use the bottom. Step three: write each answer as coordinates, with exact fractions. Step four: check by substituting back. The trap is one coordinate only. Minus five thirds is not a point. Another trap: setting the denominator to nought for the x axis. That gives the asymptote, not an intercept.

Worked example. November twenty twenty four. A curve has equation y equals five x minus two, over, three x plus two. Find the coordinates of the point where it meets the x axis, and the point where it meets the y axis. Two marks. Step one: the y axis. Put x equals nought. The top is minus two. The bottom is two. So y is minus one. The point is nought, minus one. Step two: the x axis. Set the top to nought. Five x minus two is nought, so x is two fifths. The point is two fifths, nought. Check by substituting. At x equals two fifths, the top is nought. The bottom is sixteen fifths, which is not nought. So y is nought, as needed. A tempting wrong route is to set the bottom to nought for the x axis. Three x plus two is nought gives minus two thirds. But that is the asymptote, which the curve never reaches. Here is the curve with its two points. The dashed lines are the asymptotes. So the curve meets the x axis at two fifths, nought, and the y axis at nought, minus one. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is giving one number only. Minus one is not enough. The question asks for coordinates, so write nought, minus one.

Your turn. Now you try, from June twenty twenty three. A curve has equation y equals three minus two x, over, x plus six. Find where it crosses the x axis, and where it crosses the y axis. Write your answer, then choose Continue to Answer.

Answer. For the x axis, set the top to nought. Three minus two x is nought, so two x is three, and x is three over two. The point is three over two, nought. For the y axis, put x equals nought. The top is three. The bottom is six. So y is a half. The point is nought, a half. The most common wrong answer is a sign slip, giving x equals minus three over two. Check: put x equals three over two in the top. You get nought. Remember: y axis, put x equals nought. x axis, top equals nought. Write coordinates, and check.
