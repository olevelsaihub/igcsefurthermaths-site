Drawing lines for an inequality graph

Idea. Think of a straight road on a map. You only need two places, then a ruler. An equation like y equals two x plus five links x and y. Every pair that fits is a point, and the points make a straight line. The easiest points are where the line crosses the axes. On the y axis, x is zero. On the x axis, y is zero. So put x equals zero to find the y crossing, and y equals zero to find the x crossing. Y equals a number is a flat, horizontal line. X equals a number is an upright, vertical line. A line through the origin needs another point, because both crossings are the origin. The exam says: draw the line with equation. Find two points for each line and rule it across the whole grid.

Method. Step one: put x equals zero and solve for y, then put y equals zero and solve for x. Step two: if both are the origin, or one is off the grid, choose another x. Step three: plot the points using the scale on the axes. Step four: join them with a ruler and extend across the whole grid. Label each line with its equation. Step five: check one extra point. The trap is a sign slip, so take care with minus signs.

Worked example. June twenty twenty three. Draw the lines y equals two x plus five, four y equals x minus eight, and five y plus three x equals thirty. Three marks. Line one. x zero gives y five, so the point nought, five. y zero gives two x equals minus five, so x is minus two point five. Line two. x zero gives four y equals minus eight, so y is minus two. y zero gives x equals eight. Line three. x zero gives five y equals thirty, so y is six. y zero gives three x equals thirty, so x is ten. Now plot the six points and rule each line across the whole grid. Label them. Check. On line one, x equals minus four gives y equals minus three. On line two, four times minus three is minus twelve, which is minus four minus eight. Both lines pass through minus four, minus three. A tempting slip is a sign error. In line two, zero equals x minus eight gives x equals eight, not minus eight. So all three lines are drawn, ruled across the grid and labelled. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is to draw only between the two plotted points. Later parts need the lines to meet, so rule right across the grid.

Your turn. Now you try, from November twenty twenty. Sketch each line, and show where each crosses the axes. Write your answer, then choose Continue to Answer.

Answer. Line one is flat. It crosses only the y axis, at nought, six. Line two: x zero gives y ten. y zero gives x ten. So nought ten, and ten nought. Line three: x zero gives y minus five. y zero gives two x equals five, so x is two point five. Sketch the lines through those points. A common wrong answer gives y equals six an x crossing. It never crosses the x axis. Remember: two points, ruler across the grid, label, check.
