Idea. On a street grid, a friend walks three blocks east and four blocks north. The straight path is five blocks, by Pythagoras. The length between two points on a graph is found the same way. The distance formula is the square root of: change in x squared, plus change in y squared. A change is the second value minus the first. Exact means we leave the answer as a surd, not a decimal. A surd is a square root that is not a whole number. To simplify, take out the largest square number: root twenty is root four times root five, which is two root five. These questions ask for an exact length, or to show a triangle is isosceles. The length is a tool. Always finish by saying what the lengths prove.

Method. Step one: write the two points and find the change in x and the change in y. Take care with negatives: three minus minus four is seven. Step two: square each, add, and take the square root. Step three: simplify the surd with the largest square factor. Step four: if lengths are compared, use them and write a conclusion. The trap is squaring only one change.

Worked example. June twenty nineteen. A is two, six. B is six, eight. C is four, two. Find the exact length of A B, B C and A C. Four marks. A B: the change in x is six minus two, which is four. The change in y is eight minus six, which is two. So A B is the square root of sixteen plus four, which is root twenty. Root twenty is not simplest. Twenty is four times five, and four is a square. So A B is two root five. B C: the change in x is four minus six, which is minus two. The change in y is two minus eight, which is minus six. Squares are positive: four plus thirty six is forty. Root forty is two root ten. A C: the changes are two and minus four. Four plus sixteen is twenty. So A C is also two root five. Notice A B and A C are equal. A tempting wrong route is to use the calculator and write four point four seven. The question says exact, so a decimal loses the accuracy mark. Leave it as two root five. So A B is two root five, B C is two root ten, and A C is two root five. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is to write the root of sixteen plus four as four plus two. It is root twenty, not six. You cannot take the root of each part.

Your turn. Now you try, from June twenty twenty five. A is three, two. B is eight, three. C is four, seven. Show that A B C is an isosceles triangle. Write your answer, then choose Continue to Answer.

Answer. A B: changes five and one, so root twenty five plus one, which is root twenty six. A C: changes one and five, so root one plus twenty five, also root twenty six. A B and A C are both root twenty six, so they are equal. Two sides are equal, so the triangle is isosceles. That sentence is the conclusion the mark needs. The most common wrong answer checks only A B and B C. B C is root thirty two, so the student wrongly says not isosceles. Check every pair of sides. Remember: changes in x and y, square, add, root, simplify, then use the lengths and conclude.
