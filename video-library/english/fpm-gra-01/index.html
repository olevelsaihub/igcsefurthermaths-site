Idea. A table of values pairs each input x with its output y. To substitute is to replace the letter with a number. Put x equals two into y equals two x plus one, and y is five. Log base three of nine asks: what power of three gives nine? The answer is two. Calculators have no base three key, so use change of base: L N of the number, over L N of three. L N is the natural log key. Trig curves in this paper use radians, not degrees. Set the calculator to R A D. Sine of one is point eight four in radians, but nearly nought in degrees. This question gives a table with some y values missing. You fill each empty box, to the decimal places asked.

Method. Step one: copy the equation and check the calculator mode. Step two: recompute one printed value. If it matches, you are set. Step three: substitute each missing x, with brackets for negatives and change of base for logs. Step four: round to the places asked. Step five: look along the row. Values should change smoothly. Here six sticks out where nine belongs. That is a key slip.

Worked example. June twenty twenty five. Complete the table of values for y equals log base three of, four minus x, plus three, to two decimal places. Two marks. Three boxes are empty: x equals nought point five, one point five and two point five. First, test a printed value. For x equals two, three plus L N two over L N three is three point six three. It matches. Step two: x equals nought point five. Four minus nought point five is three point five. Ln three point five over L N three is one point one four. Add three: four point one four. Now x equals one point five. That gives three point eight three. For x equals two point five, L N one point five over L N three is point three six nine one. Three point three six nine one rounds to three point three seven. A tempting wrong route is the calculator log key. That is base ten, not base three. It gives three point five four, not four point one four. Check the pattern. The points fall steadily, faster near x equals four, on a smooth curve. No value jumps out. So the missing values are four point one four, three point eight three and three point three seven. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is chopping instead of rounding. The third digit of three point three six nine one is nine, so it rounds up to three point three seven.

Your turn. Now you try, from January twenty twenty two. x is in radians. Complete the table for y equals sine x, minus three cosine two x, minus nought point five, to one decimal place. Write your answer, then choose Continue to Answer.

Answer. Set R A D. Test x equals one: it gives one point six, as printed. Now x equals nought gives minus three point five, and x equals nought point five gives minus one point six. For x equals one point six, the value is three point four nine, so three point five. For x equals two, it is two point three seven, so two point four. The most common wrong answer is degree mode. Then x equals nought point five gives minus three point five, not minus one point six. Every trig value is wrong. Remember: check the mode, test a printed value, substitute with brackets, then round.
