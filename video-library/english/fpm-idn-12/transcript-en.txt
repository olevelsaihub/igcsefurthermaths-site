Idea. No real number squared is negative. Three squared is nine, and minus three, all squared, is also nine. So no real number squares to minus nineteen. A root is a value of x that makes an expression zero. A real root is a root that is a real number. The discriminant tells you how many real roots a quadratic has. For a x squared plus b x plus c, it is b squared minus four a c. Positive means two roots, zero means one, negative means none. Now a cubic. If it is x minus k times a quadratic, and the quadratic has no real roots, the only real root is k. The curve crosses the x axis once. The question says hence show that there is only one real root. Hence means use the result from the part before. Show that means the result is given, and your working must prove it. Divide, find the discriminant, say what it means, and name the root.

Method. Step one: divide by the known factor to get the quadratic. Step two: work out b squared minus four a c, showing the numbers. Step three: state that it is negative, so no real roots. Step four: the only real root comes from the linear factor. Name it. The trap is writing the negative number and stopping. Always write what it means.

A tempting wrong route is b squared plus four a c. That gives thirty seven, which wrongly suggests two real roots. The discriminant has a minus. So the only real root is x equals minus one.
