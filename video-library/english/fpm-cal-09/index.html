Maximum or minimum? Using the second derivative

Idea. Walk over a hill. Going up, the gradient is positive. At the top it is zero. Going down, it is negative. So at a hilltop the gradient is falling, from positive to zero to negative. The second derivative, d two y by d x squared, is the derivative of d y by d x. It tells you whether the gradient is increasing or decreasing. Positive means a minimum. Negative means a maximum. Try y equals x cubed minus three x. The second derivative is six x. At x equals one it is six, positive, so a minimum. At x equals minus one it is minus six, negative, so a maximum. So these questions say determine the nature of the stationary points. You say maximum or minimum, and justify it with the value or sign of the second derivative.

Method. Step one: find the second derivative, or use the one given in an earlier part. Step two: put each stationary x value into it. You need the sign at each point separately. Step three: read the sign. Negative is a maximum, positive is a minimum. The trap is swapping them. Remember: positive is a smile, so a minimum. Step four: write a conclusion for each point, quoting the value or sign as the reason. The accuracy mark needs both the word and the evidence.

Worked example. June twenty twenty one. The curve is y equals x over x squared plus four. Part b gives the second derivative. Hence determine the nature of each stationary point. Two marks. The stationary points are x equals two and minus two. Start with two. The top is two times two times four minus twelve, which is minus thirty two. The bottom is eight cubed, five hundred and twelve. The value is minus one sixteenth, which is negative. So the point two, a quarter, is a maximum, because the second derivative is negative. Now x equals minus two. The top is two times minus two times minus eight, which is thirty two. Over five hundred and twelve, that is plus one sixteenth. Positive, so a minimum. A tempting wrong route is to put x equals two into d y by d x. That gives nought, which only confirms the point is stationary. It cannot tell you the nature. Check with the graph. A top at x equals two, and a bottom at x equals minus two. It matches. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is swapping the rule, or writing maximum with no reason. You must quote the sign of the second derivative.

Your turn. Now you try, from June twenty twenty two. The curve y equals f of x passes through four, minus one hundred and four. f dash of x means the derivative. It is four x cubed minus twelve x squared minus nineteen x plus twelve. Show that the curve has a maximum where x is nought point five. Write your answer, then choose Continue to Answer.

Answer. First show it is stationary. Put x equals nought point five into f dash of x. That gives nought point five, minus three, minus nine point five, plus twelve, which is nought. So the gradient is zero there. Differentiate again. f double dash of x, the second derivative, is twelve x squared minus twenty four x minus nineteen. At nought point five it is three, minus twelve, minus nineteen, which is minus twenty eight. Negative, so it is a maximum. The most common wrong answer skips the first check and only works out f double dash. Without showing f dash of nought point five is nought, the show that is not complete, so a mark is lost. Remember: second derivative, substitute each x, positive minimum, negative maximum, and give the reason.
