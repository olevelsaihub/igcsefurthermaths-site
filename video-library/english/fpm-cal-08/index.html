Finding stationary points

Idea. Walk over a hill. At the very top, for a moment, the path is level. It is not going up or down. On a curve, a point like that is called a stationary point, and the gradient there is zero. The gradient is d y by d x. So to find stationary points, set d y by d x equal to nought and solve for x. Then put each x into the curve to get y. For a fraction, there is a shortcut. A fraction equals zero only when its top is zero. So after the quotient rule, set the numerator equal to nought. So these questions say use calculus to find the stationary points. Give the full coordinates, both x and y, for every stationary point.

Method. Step one: differentiate. Step two: set d y by d x to nought. For a fraction, set only the numerator to nought, because a fraction is zero only when its top is zero. Step three: solve for every x. A square gives two answers, plus and minus. Missing one root loses a whole point. Step four: put each x into the original curve for y. Never into d y by d x, which just gives nought again.

Worked example. A real question from June twenty twenty one. The curve is y equals x over x squared plus four. Using calculus, find the coordinates of the stationary points. Five marks. Step one: differentiate with the quotient rule. u is x, with derivative one. v is x squared plus four, with derivative two x. The top simplifies to four minus x squared. Step two: set d y by d x to nought. A fraction is zero when its top is zero, so four minus x squared equals nought. The bottom is never zero. Step three: x squared equals four gives x equals plus or minus two. A tempting wrong route is to take only x equals two. That misses a whole stationary point. Step four: put each x into the curve. At x equals two, y is two over eight, a quarter. At x equals minus two, y is minus two over eight, minus a quarter. Here is the curve with both points. The top is at two, a quarter. The bottom is at minus two, minus a quarter. This matches the working. The exam answer: the stationary points are two, a quarter and minus two, minus a quarter. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is putting the x values into d y by d x to find y. That just gives nought. The y value comes from the curve.

Your turn. Now you try, from November twenty twenty. The curve is y equals x cubed minus three x squared minus twenty four x plus six. Use calculus to find the coordinates of each stationary point. Write your answer, then choose Continue to Answer.

Answer. Differentiate: three x squared minus six x minus twenty four. Set it to nought and take out the common factor three: x squared minus two x minus eight. That factorises to x minus four, times x plus two. Put each x into the curve. At four: sixty four, minus forty eight, minus ninety six, plus six, is minus seventy four. At minus two: minus eight, minus twelve, plus forty eight, plus six, is thirty four. The most common wrong answer puts the x values into d y by d x, which gives nought, or stops at the x values. Both lose the y marks. Always write full coordinates. Remember: differentiate, set to zero, solve for every root, then find y from the curve.
