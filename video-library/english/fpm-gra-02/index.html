Drawing the graph from your table

Idea. Think of a dot-to-dot picture. The dots come first, then you join them. A graph is the same. Each column of a table is one point: x is how far across, y is how far up. Join the dots with one smooth curve, drawn freehand, which means by hand with no ruler. A ruler makes sharp corners that the real curve does not have. The question gives an interval, like nought up to three point five. The curve starts at the first point and stops at the last. This question says: on the grid, draw the graph of this equation. You use your table, plot the points and draw one smooth curve.

Method. Step one: read the scale on each axis. How much is a small square worth? If a big square is one unit with five small squares, each is point two. Most plotting errors are scale errors. Step two: plot every point with a small neat cross, including both end points. Step three: if one point is out of line, recalculate it. Step four: draw one smooth curve through all the points. Step five: stop at the ends of the interval. The trap is a ruler.

Worked example. June twenty twenty five. On the grid, draw the graph of y equals log base three of, four minus x, plus three, from x equals nought to three point five. Two marks. The table from part a gives the points. Step one: the table. Each column is a point. Nought, four point two six. Nought point five, four point one four. One, four. One point five, three point eight three. Then on to three point five, two point three seven. Step two: plot all eight points with small crosses. Include both end points. The y values run from two point three seven to four point two six. The drops in y grow: point one two, point one four, point one seven, up to point six three. So the curve gets steeper, heading for the line x equals four. Step four: draw one smooth freehand curve from the first point to the last. Do not go past x equals three point five. A tempting wrong route is to join the dots with a ruler. That gives straight pieces with corners, so the curve mark is lost. So the graph is a smooth falling curve through all eight points, steeper to the right. This explanation is by olevels dot com, not an official mark scheme.

Common mistake. A common mistake is bending the curve to reach a wrong point. If one point is off the pattern, recalculate it. Say you plotted three point three at one point five. The true value is three point eight three.

Your turn. Now you try, from January twenty twenty. Part a: complete the table for y equals x minus three over x squared. Part b: draw the graph for x from nought point five to six. Write your answer, then choose Continue to Answer.

Answer. First the table. At x equals one, y is minus two. At one point five, y is nought point two. At four, three point eight. At five, four point nine. Now plot all eight points, including the low one at minus eleven point five. Draw one smooth curve. It rises steeply, then flattens, and stops at x equals six. The most common wrong answer leaves out the end point at x equals nought point five, because it is far down the page. The curve then misses part of the interval. Remember: read the scale, plot every point with a cross, draw one smooth curve, and stop at the ends.
