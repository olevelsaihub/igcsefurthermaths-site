Formulas and key facts

Must-know formulas and facts for Pearson Edexcel International GCSE Further Pure Mathematics (4PM1). Each paper prints a formulae sheet (On the formulae sheet); everything marked Learn it is not on it, so learn it.

On the formulae sheetLearn theseExam habits

On the formulae sheet

Know where each one is and how to use it; you do not need to memorise these.

Mensuration

Surface area of a sphere

On the formulae sheet

$4\pi r^2$

Curved surface area of a cone

On the formulae sheet

$\pi r \times$ slant height

Add $\pi r^2$ for the base if the question wants the total surface area.

Volume of a sphere

On the formulae sheet

$\frac{4}{3}\pi r^3$

Series

Arithmetic series

On the formulae sheet

$S_n = \frac{n}{2}\left[2a + (n-1)d\right]$

Learn the $n$th term and $S_n = \frac{n}{2}(a + l)$ yourself (below).

Geometric series, sum to $n$ terms

On the formulae sheet

$S_n = \frac{a(1 - r^n)}{1 - r}$

Geometric series, sum to infinity

On the formulae sheet

$S_\infty = \frac{a}{1 - r}$ for $|r| < 1$

State $|r| < 1$ when you use it: it is often a mark.

Binomial series

On the formulae sheet

$(1 + x)^n = 1 + nx + \frac{n(n-1)}{2!}x^2 + \dots + \frac{n(n-1)\dots(n-r+1)}{r!}x^r + \dots$

Valid for $|x| < 1$, any rational $n$.

Calculus

Quotient rule

On the formulae sheet

$\frac{d}{dx}\left(\frac{f(x)}{g(x)}\right) = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2}$

The product rule is NOT on the sheet (below).

Trigonometry

Cosine rule

On the formulae sheet

$a^2 = b^2 + c^2 - 2bc\cos A$

The sine rule and the area formula are NOT on the sheet (below).

Tangent

On the formulae sheet

$\tan\theta = \frac{\sin\theta}{\cos\theta}$

Addition formulae

On the formulae sheet

$\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B$

$\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$

Addition formula for tan

On the formulae sheet

$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A\tan B}$

Logarithms

Change of base

On the formulae sheet

$\log_a x = \frac{\log_b x}{\log_b a}$

Learn these: not on the sheet

Logarithms and indices

Log and index form

Learn it

$y = a^x \iff x = \log_a y$

So $\log_a 1 = 0$ and $\log_a a = 1$.

Log laws

Learn it

$\log_a xy = \log_a x + \log_a y,\quad \log_a \frac{x}{y} = \log_a x - \log_a y,\quad \log_a x^k = k\log_a x$

There is no law for $\log_a(x + y)$.

Natural log

Learn it

$e^{\ln x} = x$ and $\ln e^x = x$

Use ln to bring a power down: $a^x = b \Rightarrow x = \frac{\ln b}{\ln a}$.

Surds

Learn it

$\sqrt{ab} = \sqrt a\sqrt b,\quad \frac{1}{\sqrt a} = \frac{\sqrt a}{a},\quad \frac{1}{a + \sqrt b} = \frac{a - \sqrt b}{a^2 - b}$

Rationalise by multiplying top and bottom by the conjugate.

Quadratics

Quadratic formula

Learn it

$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$

Discriminant

Learn it

$b^2 - 4ac > 0$: two real roots; $= 0$: equal roots; $< 0$: no real roots

"Real roots" (one or two) means $b^2 - 4ac \ge 0$.

Completing the square

Learn it

$ax^2 + bx + c = a\left(x + \frac{b}{2a}\right)^2 + c - \frac{b^2}{4a}$

The least (or greatest) value is $c - \frac{b^2}{4a}$, at $x = -\frac{b}{2a}$.

Sum and product of roots

Learn it

$\alpha + \beta = -\frac{b}{a},\quad \alpha\beta = \frac{c}{a}$

A quadratic with roots $p$ and $q$: $x^2 - (p + q)x + pq = 0$.

Useful identities

Learn it

$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta,\quad (\alpha - \beta)^2 = (\alpha + \beta)^2 - 4\alpha\beta$

$\alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta)$

Identities and inequalities

Factor theorem

Learn it

$f(a) = 0 \iff (x - a)$ is a factor of $f(x)$

For $(px - q)$ use $f\left(\frac{q}{p}\right) = 0$.

Remainder theorem

Learn it

$f(x) \div (x - a)$ leaves remainder $f(a)$

Quadratic inequality

Learn it

$(x - a)(x - b) < 0 \Rightarrow a < x < b$; $> 0 \Rightarrow x < a$ or $x > b$ (for $a < b$)

Sketch the parabola to check which side.

Inequality rule

Learn it

Multiplying or dividing by a negative number reverses the inequality sign.

Series

Arithmetic: $n$th term and sum

Learn it

$u_n = a + (n - 1)d,\quad S_n = \frac{n}{2}(a + l)$

$l$ is the last term.

Geometric: $n$th term

Learn it

$u_n = ar^{n-1}$

To find $n$, take logs: $r^{n} = k \Rightarrow n = \frac{\ln k}{\ln r}$.

Sigma notation

Learn it

$\sum_{r=1}^{n} 1 = n$; $\sum_{r=1}^{n} (pr + q)$ is an arithmetic series

Count the terms: $r = k$ to $n$ gives $n - k + 1$ terms.

Coordinate geometry

Distance and midpoint

Learn it

$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$, midpoint $\left(\frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2}\right)$

Gradient and line

Learn it

$m = \frac{y_2 - y_1}{x_2 - x_1},\quad y - y_1 = m(x - x_1)$

"Form $ax + by + c = 0$" means integers $a$, $b$, $c$.

Parallel and perpendicular

Learn it

Parallel: $m_1 = m_2$. Perpendicular: $m_1 m_2 = -1$

Dividing a line in the ratio $m : n$

Learn it

$\left(\frac{nx_1 + mx_2}{m + n}, \frac{ny_1 + my_2}{m + n}\right)$

The point is $\frac{m}{m+n}$ of the way from the first point.

Vectors

Magnitude

Learn it

$|x\mathbf i + y\mathbf j| = \sqrt{x^2 + y^2}$

Unit vector

Learn it

$\hat{\mathbf a} = \frac{\mathbf a}{|\mathbf a|}$

Position vectors

Learn it

$\overrightarrow{AB} = \mathbf b - \mathbf a$

Parallel vectors are multiples: $\mathbf u = k\mathbf v$. Collinear: parallel and sharing a point.

Differentiation

Standard derivatives

Learn it

$\frac{d}{dx}x^n = nx^{n-1},\ \frac{d}{dx}e^{ax} = ae^{ax},\ \frac{d}{dx}\sin ax = a\cos ax,\ \frac{d}{dx}\cos ax = -a\sin ax$

Angles must be in radians.

Product rule

Learn it

$\frac{d}{dx}(uv) = u\frac{dv}{dx} + v\frac{du}{dx}$

Chain rule

Learn it

$\frac{dy}{dx} = \frac{dy}{du}\times\frac{du}{dx}$

Rates of change: $\frac{dV}{dt} = \frac{dV}{dr}\times\frac{dr}{dt}$.

Tangent and normal

Learn it

Tangent gradient $m = \frac{dy}{dx}$ at the point; normal gradient $-\frac{1}{m}$

Stationary points

Learn it

$\frac{dy}{dx} = 0$; then $\frac{d^2y}{dx^2} > 0$ minimum, $< 0$ maximum

Small changes

Learn it

$\delta y \approx \frac{dy}{dx}\,\delta x$

Integration

Standard integrals

Learn it

$\int x^n\,dx = \frac{x^{n+1}}{n+1} + c\ (n \ne -1),\ \int e^{ax}dx = \frac{1}{a}e^{ax} + c$

$\int \sin ax\,dx = -\frac{1}{a}\cos ax + c,\ \int \cos ax\,dx = \frac{1}{a}\sin ax + c$

Area

Learn it

$A = \int_a^b y\,dx$; between curves $\int_a^b (y_{\text{top}} - y_{\text{bottom}})\,dx$

Area below the $x$-axis comes out negative: work out each piece separately.

Volume of revolution

Learn it

About the $x$-axis: $V = \pi\int_a^b y^2\,dx$. About the $y$-axis: $V = \pi\int_c^d x^2\,dy$

Kinematics

Learn it

$v = \frac{ds}{dt},\ a = \frac{dv}{dt}$; $s = \int v\,dt,\ v = \int a\,dt$

At rest: $v = 0$. Distance travelled: split the time where $v$ changes sign.

Trigonometry

Sine rule

Learn it

$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$

Finding an angle can give two answers: $\theta$ and $180^\circ - \theta$.

Area of a triangle

Learn it

$\frac{1}{2}ab\sin C$

Radians

Learn it

$\pi$ rad $= 180^\circ$; arc length $s = r\theta$; sector area $\frac{1}{2}r^2\theta$

$\theta$ must be in radians for these.

Pythagorean identity

Learn it

$\sin^2\theta + \cos^2\theta = 1$

Double angles

Learn it

$\sin 2A = 2\sin A\cos A,\ \cos 2A = \cos^2 A - \sin^2 A = 2\cos^2 A - 1 = 1 - 2\sin^2 A$

$\tan 2A = \frac{2\tan A}{1 - \tan^2 A}$. All come from the addition formulae with $B = A$.

Exact values

Learn it

$\sin 30^\circ = \frac12,\ \cos 30^\circ = \frac{\sqrt3}{2},\ \tan 30^\circ = \frac{1}{\sqrt3};\ \sin 45^\circ = \cos 45^\circ = \frac{1}{\sqrt2},\ \tan 45^\circ = 1;\ \sin 60^\circ = \frac{\sqrt3}{2},\ \cos 60^\circ = \frac12,\ \tan 60^\circ = \sqrt3$

Volumes with trig

Learn it

Cone $\frac13\pi r^2h$, pyramid $\frac13 \times$ base area $\times h$, prism = cross-section $\times$ length

Exam habits that keep the marks

  • Give answers to 3 significant figures unless the question asks for something else.
  • "Exact" means a surd, fraction, $\pi$ or $\ln$ form: no decimals.
  • "Show that" prints the answer, so every step must be written: a missing step loses the marks.
  • "Hence" means use the part before. "Hence or otherwise" lets another correct method score.
  • Trig equations give a range: find every solution in it, in degrees or radians as the question uses.
  • Calculus with trig works in radians. Set the calculator before you start.
  • Keep full calculator values in the working and round only the final answer.
