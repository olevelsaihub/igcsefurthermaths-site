Further Pure Mathematics / Show that: reaching a given result

Pearson Edexcel · International GCSE Further Pure Mathematics · 4PM1

Show that: reaching a given result

You are given the final result and must prove it is true using clear working. The answer is printed, so the marks are for the steps.

Command words: Show that, ShowUsually 2 to 4 marksAbout 1 minute per mark

What Pearson asks

You are given the final result and must prove it is true using clear working. The answer is printed, so the marks are for the steps.

How the marks are earned

Method marks are for starting correctly and for each key step on the way. The final accuracy mark is only given when every step is shown and the last line matches the printed answer exactly.

Method

  1. Write down the formula or fact you start from.

    Why: The first method mark is for a correct start.

  2. Substitute values and write each line of working.

    Why: Skipped steps lose the accuracy mark, because the answer is already known.

  3. Simplify one step at a time.

    Why: Each small step is checkable, so errors are easy to spot.

  4. Finish on the exact printed result and add 'as required'.

    Why: The last line must match the question, not just be close.

Answer frame

Formula, then substitution, then simplified lines, then the printed result.

Common errors

Inferred, not measured: Inferred from how 4PM1 command words are usually credited; not measured student-error statistics.

  • Working backwards from the printed answer instead of towards it.
  • Jumping from an unsimplified line straight to the answer.
  • Using a rounded decimal part way through and so only getting close to the result.
  • Copying the printed answer on the last line with no working that leads to it.

Worked illustration

June 2024 · Paper 1 · Q3(a)

The complete original question is shown; the illustration answers part (a).

Model answer · written by olevels.com, not an official Pearson mark scheme

$r = 1$: $5(1) - 3 = 2$; $r = 2$: $5(2) - 3 = 7$; $r = 3$: $12$

So the series is arithmetic with $a = 2$ and $d = 5$, and there are $n$ terms.

$\sum_{r=1}^{n}(5r - 3) = \frac{n}{2}[2(2) + (n-1)(5)]$

$= \frac{n}{2}[4 + 5n - 5]$

$= \frac{n}{2}(5n - 1)$

So the sum is $\frac{n}{2}(5n - 1)$, as required.

Why it earns the marks

The first term and common difference earn the first method mark, the sum formula earns the second, and the shown simplification earns the accuracy mark.
