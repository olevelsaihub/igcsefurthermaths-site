Further Pure Mathematics / Write down and state: one-step answers

Pearson Edexcel · International GCSE Further Pure Mathematics · 4PM1

Write down and state: one-step answers

You need to give a result you can see or recall without long working. Little or no calculation is expected.

Command words: Write down, StateUsually 1 to 2 marksAbout 1 minute in total

What Pearson asks

You need to give a result you can see or recall without long working. Little or no calculation is expected.

How the marks are earned

These are usually independent (B) marks, given for the correct answer alone. If there is no working, the answer must be exactly right, so it is worth a quick check.

Method

  1. Read the question for exactly what is asked.

    Why: The answer is often a single value, range or fact.

  2. Use the rule or result you know.

    Why: No long method is needed.

  3. Write the answer clearly in the right form.

    Why: A B mark needs the correct final answer.

  4. Check inequality signs and units.

    Why: Small details decide the mark.

Answer frame

One short line with the answer, plus a brief reason if it helps.

Common errors

Inferred, not measured: Inferred from how 4PM1 command words are usually credited; not measured student-error statistics.

  • Doing a long calculation when a quick recall was enough.
  • Using the wrong inequality sign, for example $\le$ instead of $<$.
  • Leaving out units or the variable.
  • Writing a rounded decimal instead of the exact value.

Model answer · written by olevels.com, not an official Pearson mark scheme

The expansion is of $(1 + bx)^{-3}$ with $b = \frac{1}{3}$

Valid when $\left|\frac{x}{3}\right| < 1$

$|x| < 3$, i.e. $-3 < x < 3$

Why it earns the marks

This is one independent mark for the correct range. Using the condition $|\frac{x}{3}| < 1$ gives the right bounds and the right strict signs.
