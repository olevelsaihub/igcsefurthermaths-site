Further Pure Mathematics / Solve: every solution in the range

Pearson Edexcel · International GCSE Further Pure Mathematics · 4PM1

Solve: every solution in the range

You must find all values that satisfy the equation or inequality. Trig questions give a range in degrees or radians, and every solution in that range is needed.

Command word: SolveUsually 3 to 5 marksAbout 1 minute per mark

What Pearson asks

You must find all values that satisfy the equation or inequality. Trig questions give a range in degrees or radians, and every solution in that range is needed.

How the marks are earned

Method marks are for rearranging or factorising correctly and for using an inverse function. Accuracy marks are for each correct solution, so missing a solution loses a mark.

Method

  1. Rearrange so one side is zero, or one trig function is on its own.

    Why: Factorising only works when one side is zero.

  2. Factorise or use an inverse function.

    Why: This is where the method marks are.

  3. Find every solution in the stated range.

    Why: Trig functions repeat, so there is often more than one answer.

  4. Check each answer lies inside the range.

    Why: Solutions outside the range score no marks.

Answer frame

Rearrange, factorise, solve each factor, list all solutions in the range.

Common errors

Inferred, not measured: Inferred from how 4PM1 command words are usually credited; not measured student-error statistics.

  • Dividing both sides by a common factor and losing solutions.
  • Giving only the calculator value and missing the second solution.
  • Including answers outside the stated range.
  • Mixing degrees and radians.

Worked illustration

January 2020 · Paper 1 · Q8(b)

The complete original question is shown; the illustration answers part (b).

Model answer · written by olevels.com, not an official Pearson mark scheme

$\frac{2\sin y}{\cos y} + 5\sin y = 0$

$\sin y\left(\frac{2}{\cos y} + 5\right) = 0$ (multiplying by $\cos y$: $\sin y(2 + 5\cos y) = 0$)

$\sin y = 0 \Rightarrow y = 0$ or $y = 180$

$2 + 5\cos y = 0 \Rightarrow \cos y = -\frac{2}{5}$

$y = \cos^{-1}(-0.4) = 180^\circ - 66.42^\circ = 113.6^\circ$ (the only value in $0 \le y \le 180$)

So $y = 0$, $y = 113.6$ and $y = 180$.

Why it earns the marks

The method marks are for writing tan as sin over cos and factorising, and for solving $\cos y = -0.4$. The accuracy marks are for $0$ and $180$, and for $113.6$.
