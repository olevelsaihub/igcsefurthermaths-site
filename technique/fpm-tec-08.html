Express, complete and form: writing in a required form

You must write something in the exact form or layout the question states. The form is part of the answer.

Command words: Express, Complete, Form, Expand, FactoriseUsually 1 to 3 marksAbout 1 minute per mark

What Pearson asks

You must write something in the exact form or layout the question states. The form is part of the answer.

How the marks are earned

Method marks are for using the right rule to change the form. The accuracy mark is only given when the final answer is in the form asked for, even if an equivalent form is correct maths.

Method

  1. Read the form the question requires.

    Why: The answer must match it.

  2. Apply the right rule, for example the definition of a log.

    Why: This earns the method mark.

  3. Write the answer on its own line in the required form.

    Why: It makes the final answer easy to credit.

  4. Check by substituting a value.

    Why: A quick test catches slips.

Answer frame

Starting statement, the rule used, final answer in the form asked.

Common errors

Inferred, not measured: Inferred from how 4PM1 command words are usually credited; not measured student-error statistics.

  • Leaving the answer in a different but equivalent form.
  • Not using the exact letters or constants named in the question.
  • Skipping the rule, so only the answer is shown.
  • Making a sign error when expanding or factorising.

Worked illustration

June 2021 · Paper 1 · Q8(b)(i)

The complete original question is shown; the illustration answers part (b)(i).

Model answer · written by olevels.com, not an official Pearson mark scheme

$\log_p x = 3$

By the definition of a log, the base $p$ raised to the power 3 gives $x$:

$x = p^3$

Why it earns the marks

One mark is for $x = p^3$, which is written in the form asked for and comes from the definition of a log.
