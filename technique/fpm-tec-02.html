Further Pure Mathematics / Hence: using the previous part

Pearson Edexcel · International GCSE Further Pure Mathematics · 4PM1

Hence: using the previous part

You must use the result you have just found or been given to answer this part. With 'hence or otherwise' you may use any valid method.

Command words: Hence, Hence or otherwiseUsually 2 to 4 marksAbout 1 minute per mark

What Pearson asks

You must use the result you have just found or been given to answer this part. With 'hence or otherwise' you may use any valid method.

How the marks are earned

The method mark is for clearly using the earlier result. The accuracy mark is for the final value or expression. With 'or otherwise' a correct alternative method scores the same marks.

Method

  1. Look back at the previous part and spot the result you can use.

    Why: The question is built to follow from it.

  2. Write that result down, then apply it to the new values.

    Why: This shows the examiner you used it.

  3. Carry out the calculation or simplification.

    Why: The accuracy mark is for a correct final answer.

  4. Check your answer against a quick alternative if there is time.

    Why: This catches slips in arithmetic.

Answer frame

Earlier result, then how it applies here, then the calculation, then the final answer.

Common errors

Inferred, not measured: Inferred from how 4PM1 command words are usually credited; not measured student-error statistics.

  • Starting again from scratch when the previous result was meant to be used.
  • Using the earlier formula with the wrong limits or values.
  • Leaving out the step that shows how the result was used.
  • Writing an answer with no working, when the working shows the method.

Worked illustration

June 2024 · Paper 1 · Q3(b)

The complete original question is shown; the illustration answers part (b).

Model answer · written by olevels.com, not an official Pearson mark scheme

$\sum_{r=1}^{60}(5r - 3) = \frac{60}{2}(5 \times 60 - 1) = 30 \times 299 = 8970$

$\sum_{r=1}^{30}(5r - 3) = \frac{30}{2}(5 \times 30 - 1) = 15 \times 149 = 2235$

$\sum_{r=31}^{60}(5r - 3) = 8970 - 2235 = 6735$

Check: 30 terms with first term 152 and last term 297 gives $15 \times 449 = 6735$.

So the sum is $6735$.

Why it earns the marks

The method mark is for using the result from part (a) twice and subtracting, and the accuracy mark is for the correct total.
