Further Pure Mathematics / Prove: identities and algebraic proofs

Pearson Edexcel · International GCSE Further Pure Mathematics · 4PM1

Prove: identities and algebraic proofs

You must show that a statement is always true, using logical steps. The same rules as 'show that' apply, with a clear line of reasoning.

Command word: ProveUsually 3 to 5 marksAbout 1 to 1.5 minutes per mark

What Pearson asks

You must show that a statement is always true, using logical steps. The same rules as 'show that' apply, with a clear line of reasoning.

How the marks are earned

Method marks are for starting from a correct identity and for each valid step. The final accuracy mark needs the two sides shown to be equal, with no gaps in the reasoning.

Method

  1. Choose one side, usually the more complicated, to work on.

    Why: You then only change one expression.

  2. Expand and substitute known identities.

    Why: Each identity you use should be a true fact.

  3. Simplify step by step towards the other side.

    Why: Every line must follow from the one before.

  4. End by stating it matches the other side.

    Why: This completes the proof.

Answer frame

Start with one side, apply identities line by line, reach the other side, write RHS or 'as required'.

Common errors

Inferred, not measured: Inferred from how 4PM1 command words are usually credited; not measured student-error statistics.

  • Treating the equation as true and working on both sides at once.
  • Using a double angle identity incorrectly.
  • Missing a step so the line of reasoning has a gap.
  • Stopping before the result matches the other side.

Worked illustration

June 2023 · Paper 1 · Q9(b)

The complete original question is shown; the illustration answers part (b).

Model answer · written by olevels.com, not an official Pearson mark scheme

LHS $= 2\sin^2 x - 6\sin x\cos x - \sin x\cos x + 3\cos^2 x = 2\sin^2 x - 7\sin x\cos x + 3\cos^2 x$

Substitute $\sin^2 x = \frac{1 - \cos 2x}{2}$, $\cos^2 x = \frac{1 + \cos 2x}{2}$, $\sin x\cos x = \frac{1}{2}\sin 2x$:

$= (1 - \cos 2x) - \frac{7}{2}\sin 2x + \frac{3}{2}(1 + \cos 2x)$

$= \frac{5}{2} + \frac{1}{2}\cos 2x - \frac{7}{2}\sin 2x$

$= \frac{1}{2}(\cos 2x - 7\sin 2x + 5)$ = RHS

Why it earns the marks

The method marks are for expanding correctly and replacing with double angle identities. The accuracy mark is for the shown simplification ending on the right-hand side.
